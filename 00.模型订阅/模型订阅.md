## 免费模型

**文本模型**

glm-4.7-flash

类似deep-seek-v4-flash。仅仅支持文本，不支持图片。



**视觉模型**

glm-4.6v-flash

图片识别。



**文生图**

 CogView-3-Flash



使用手动通过API方式调用，不支持SSE。

该模型没有记忆，一次调用即完整会话。

```
https://open.bigmodel.cn/api/paas/v4/images/generations
POST
Authorization
Bearer 你的token

Content-Type
application/json

{
  "model": "cogview-3-flash",
  "prompt": "帮我生成一张图片，程序员在使用AI。风格东方一点，严屹宽",
  "size": "1024x1024"
}
```



**文生视频**

cogvideox-flash



创建任务(异步)

```
https://open.bigmodel.cn/api/paas/v4/videos/generations
POST
Authorization
Bearer 你的token

Content-Type
application/json

{
  "model": "cogvideox-flash",
  "prompt": "我中了一张100万彩票，十分开心",
  "duration": 5,
  "quality":"quality"
}
```

查询生成结果

```
https://open.bigmodel.cn/api/paas/v4/async-result/任务id
GET
```
