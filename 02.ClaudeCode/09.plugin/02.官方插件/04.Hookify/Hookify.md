# 作用

用自然语言自动帮你生成对应的钩子（Hook）规则文件。

命令格式

```
/hookify [你的自然语言描述]
```



# 案例

- **阻止危险操作**：
  输入：`/hookify 当我使用 rm -rf 命令时警告我`
  结果：它会自动创建一个规则，监测 Bash 命令，一旦匹配到 `rm -rf` 就会触发警告或阻止。
- **代码规范检查**：
  输入：`/hookify 提交代码前提醒我删除 console.log`
  结果：它会生成一个文件编辑钩子，扫描代码中是否包含 `console.log`，如果有则发出提醒。
- **自动化流程**：
  输入：`/hookify 保存文件后自动运行 Prettier 格式化`
  结果：它会配置一个文件保存事件监听，自动触发格式化命令。
