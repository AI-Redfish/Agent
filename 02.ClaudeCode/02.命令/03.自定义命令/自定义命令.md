

# 快速上手

在当前项目下创建如下文件：./claude/commands/testCommand.md

内容如下：

```
帮我在项目目录下创建一个文件，说明下2026最赚钱的项目。
```

然后在claude交互中就可以输入如下触发该命令：

```
/testCommand
```



注意：命令文件必须是md文件。



# 作用范围

项目级:/claude/commands/

用户级:c:/users/用户/.claude/commands/



# 命令层级

自定义命令可以嵌套一层文件夹，用于分类不同的命令。

```
.claude/commands/分类1/命令1
.claude/commands/分类1/命令2
.claude/commands/分类2/命令3
.claude/commands/分类2/命令4
```



# 传递参数

在当前项目下创建如下文件：./claude/commands/myWeather.md

内容如下：

```
帮我查询一下 ARGUMENTS 在 ARGUMENTS 这一天的天气.
```

然后在claude交互中就可以输入如下触发该命令：

```
/myWeather 西安 明天
```





# @文件应用

```
帮我查看 @todo.md ，告诉我有哪些代办事项。
```

文件引用的是claude运行目录下的指定文件。
