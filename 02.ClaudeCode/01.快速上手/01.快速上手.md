```

claude update
```

**更新**
```
claude install
或
claude update
```

```
winget uninstall Anthropic.ClaudeCode
```

# 初始化项目

在工作目录下的claude交互中输入如下内置命令。

**/init**

初始化CLAUDE.md文件。



CLAUDE.md用于预制上下文。



CLAUDE.md：项目共享的上下文。一般提交到git。

CLAUDE.local.md：当前项目下个人专用上下文。一般不会提交到git。

$HOME/.claude/CLAUDE.md：用户级全局上下文。
