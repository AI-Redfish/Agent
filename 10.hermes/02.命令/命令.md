# 启动命令

在终端中执行，用于启动 Hermes、配置环境、管理资源和排障。

## 启动与基础使用

```bash
# 进入交互式聊天
hermes

# 单次提问/执行一次任务
hermes chat -q "解释一下这个项目怎么运行"

# 指定模型发起一次对话
hermes chat -m anthropic/claude-sonnet-4 -q "帮我写一个 FastAPI 示例"

# 指定工具集
hermes chat -t terminal,file,web -q "检查当前项目结构并总结"

# 继续最近一次会话
hermes --continue
hermes -c

# 恢复指定会话（ID 或标题）
hermes --resume <SESSION_ID_OR_TITLE>
hermes -r <SESSION_ID_OR_TITLE>

# 使用指定 profile
hermes --profile <profile_name>
hermes -p <profile_name>

# 预加载技能
hermes --skills hermes-agent
hermes -s hermes-agent

# 跳过危险命令审批（谨慎）
hermes --yolo

# 查看版本
hermes --version
```

## 初始化、配置与健康检查

```bash
# 初始化/交互式配置向导
hermes setup

# 配置某个部分
hermes setup model
hermes setup terminal
hermes setup gateway
hermes setup tools
hermes setup agent

# 交互式选择模型/Provider
hermes model

# 查看当前配置
hermes config

# 编辑配置文件
hermes config edit

# 设置配置项
hermes config set model.provider openrouter
hermes config set model.default anthropic/claude-sonnet-4
hermes config set agent.max_turns 90

# 查看配置文件路径和 .env 路径
hermes config path
hermes config env-path

# 检查/迁移配置
hermes config check
hermes config migrate

# 健康检查
hermes doctor
hermes doctor --fix

# 查看组件状态
hermes status
hermes status --all
```

## 认证与模型 Provider

```bash
# 交互式管理凭据
hermes auth

# 添加 Provider 凭据/OAuth
hermes auth add openai
hermes auth add anthropic
hermes auth add nous
hermes auth add qwen-oauth

# 查看凭据
hermes auth list
hermes auth list <provider>

# 删除凭据
hermes auth remove <provider>
hermes auth remove <provider> <index>

# 重置 Provider 凭据池耗尽状态
hermes auth reset <provider>
```

```bash
GOOGLE_API_KEY=...
GEMINI_API_KEY=...

```

## 工具 Toolsets

```bash
# 交互式启用/禁用工具
hermes tools

# 查看所有工具及状态
hermes tools list

# 启用工具集
hermes tools enable terminal
hermes tools enable file
hermes tools enable web
hermes tools enable browser
hermes tools enable vision
hermes tools enable cronjob

# 禁用工具集
hermes tools disable browser
hermes tools disable image_gen
```

常用工具集：

| Toolset | 作用 |
|---|---|
| `terminal` | 执行 Shell 命令 |
| `file` | 读写、搜索、修改文件 |
| `web` | 联网搜索/提取网页内容 |
| `browser` | 浏览器自动化 |
| `vision` | 图片理解 |
| `image_gen` | 图片生成 |
| `tts` | 文本转语音 |
| `skills` | 技能管理 |
| `memory` | 持久记忆 |
| `session_search` | 搜索历史会话 |
| `delegation` | 子 Agent 委派 |
| `cronjob` | 定时任务 |
| `todo` | 会话内任务清单 |

> 工具启用/禁用后通常需要新会话生效：CLI 中输入 `/reset` 或重新启动 `hermes`。


## 定时任务 Cron

```bash
# 查看定时任务
hermes cron list
hermes cron list --all

# 创建定时任务
hermes cron create "30m"
hermes cron create "every 2h"
hermes cron create "0 9 * * *"

# 编辑/暂停/恢复/运行/删除任务
hermes cron edit <JOB_ID>
hermes cron pause <JOB_ID>
hermes cron resume <JOB_ID>
hermes cron run <JOB_ID>
hermes cron remove <JOB_ID>

# 查看调度器状态
hermes cron status
```

调度格式示例：

```text
30m                 # 每 30 分钟
2h                  # 每 2 小时
every monday 9am    # 每周一 9 点
0 9 * * *           # 每天 9 点（cron 表达式）
2026-06-01T09:00:00 # 单次 ISO 时间
```

## 常见排错

```bash
# 总体健康检查
hermes doctor
hermes doctor --fix

# 配置是否缺失/过期
hermes config check

# 工具是否启用
hermes tools list

# Gateway 日志（Linux/macOS/Git Bash）
grep -i "failed to send\|error" ~/.hermes/logs/gateway.log | tail -20

# Gateway 服务状态
hermes gateway status

# 技能是否安装/启用
hermes skills list
hermes skills config
```

常见注意事项：

- 修改工具、技能、部分配置后，新开会话或 `/reset` 才会生效。
- API Key 放在 `~/.hermes/.env`，普通配置放在 `~/.hermes/config.yaml`。
- Windows 上如果配置文件出现 UTF-8 BOM，可能导致模型请求异常；可用 `hermes config edit` 重新保存。
- Gateway 平台收不到消息时，先看平台权限和 `~/.hermes/logs/gateway.log`。

## background

```
/background Check all servers in the cluster and report any that are down
```

在独立的后台会话中运行 prompt，让 agent 独立处理，同时保持主聊天响应.


**工作原理**

每个 /background prompt 会生成一个独立的 agent 实例异步运行：

- 隔离会话 — 后台 agent 拥有自己的会话和对话历史。它不了解你当前的聊天上下文，只接收你提供的 prompt。

- 相同配置 — 继承当前网关配置中的模型、提供商、工具集、推理设置和提供商路由。

- 非阻塞 — 你的主聊天保持完全交互。在后台任务运行期间，你可以发送消息、运行其他命令或启动更多后台任务。

- 结果传递 — 任务完成后，结果发送回发出命令的同一聊天或频道，前缀为"✅ Background task complete"。如果失败，你会看到"❌ Background task failed"及错误信息。
