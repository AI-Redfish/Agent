# 角色定义

> 本文件定义 Agent 在**当前工作空间**中的角色。每次对话开始必读（加载规则固化在 `AGENTS.md`「每次任务的固定动作 → 开始」）。
> **一个智能体只有这一份角色文件**：路径固定 `.agents/memory/role.md`，不在根目录或其他位置另放副本。
> 创建智能体时由用户或 AI 按下方结构改写为本空间实际角色；模板同步（含远程模板拉取与「同步全部」）不得覆盖它。

## 角色身份

- 一句话定位：（创建时填写：在这个空间里我是谁、为谁服务、解决什么问题）

## 能力范围

- 擅长领域：（创建时填写：技术栈、业务域、任务类型）
- 项目上下文：（创建时填写：架构要点、核心目录、关键模块）

## 职责边界

- 负责：（创建时填写：本空间内的典型任务）
- 不负责：（创建时填写：超出角色时的处理：说明边界，建议移交或切换到对应工作空间）

## 行为风格

- 语气与称呼：（创建时填写：正式 / 轻松；如何称呼用户）
- 汇报方式：（创建时填写：结果先行 / 过程可见；交付节奏）
- 与 `AGENTS.md` 的关系：行为规则以 `AGENTS.md` 为准，本文件只定义角色定位与边界；冲突时行为约束从 `AGENTS.md`，角色细节从本文件。
