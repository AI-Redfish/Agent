# 项目相关记忆

> 温记忆 · 演进型 · 项目任务开始，以及选择构建／测试命令或沉淀目录前加载。
> 适用范围：仅本工作空间。来源：Agent 异步整理 + 用户确认。

## 沉淀输出目录约定

> 下表是各类产物与沉淀的固定默认位置，无需用户确认。本文件只读；用户指定的例外目录记录在 `.agents/memory-locations.md`，不写回这里。

所有路径相对当前工作空间根目录；不因 Git 仓库或 worktree 改变位置。仅当用户主动指定其他目录时，以用户指定为准。

| 产物类型 | 默认位置 |
| :-- | :-- |
| 用户信息、偏好、行为反馈、项目事实、参考知识等记忆 | `.agents/memory/learned/<主题>.md` |
| 有效经验、错误教训、能力缺口 | `.agents/memory/learned/<主题>.md` |
| 独立规则 / 提示词 | `.agents/rules/<主题>.md`，不得使用 `AGENTS.md` |
| Skill | `.agents/skills/<skill-name>/` |
| 脚本 / SQL / 代码片段 | `.agents/scripts/` |
| CLI | `.agents/tools/cli/` |
| MCP / 工具接口 | `.agents/tools/mcp/` |
| 知识文档 / 索引 | `.agents/docs/` |
| 模板 / 示例 / 检查清单 | `.agents/templates/` |
| 自动化流程 / 工具配置 | `.agents/workflows/` |
| 上下文交接包 | `.agents/docs/` 下的全新交接文件 |
| 审查 / 整理 / 验证日志及必要过程产物 | `.agents/history/` 下的全新文件或独立运行目录 |
| 冷记忆历史 / 摘要 / 检索记录 | `.agents/history/memory.db`，仅在宿主提供能力且用户授权时启用 |

同类主题不重复写入多份资产。默认目录只决定输出位置，不授权创建无用文件或改写既有文件；持久化写入仍须用户授权。

实际输出按本表类型映射。用户指定的例外目录以 `.agents/memory-locations.md` 为准。冷记忆路径不代表数据库或检索接口已存在。

## 特有内容的承载方式

项目描述、项目约定、环境事实、踩过的坑等本空间特有内容，在创建智能体时按固定通用内容的要求动态创建为 `.agents/memory/learned/<主题>.md` 新文件承载；不写入本文件，不修改任何模板内容。同一个坑不要在两个文件里重复写。
