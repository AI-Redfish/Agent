## 沉淀输出目录约定

> 下表是首次使用时必须向用户展示的推荐选项，不是已确认配置。本文件只读，用户选择不写回这里；确认流程与配置保存方式见 `BOOTSTRAP.md`。

`<输出根目录>` 在 Git 仓库或 worktree 中指经 Git 信息确认的原仓库根目录，其他场景指当前工作空间。对话中须展示实际绝对路径。用户可以逐类指定其他位置，或选择“暂不启用”。

| 产物类型 | 推荐位置 |
| :-- | :-- |
| 用户信息、偏好、行为反馈、项目事实、参考知识等记忆 | `<输出根目录>/.agents/memory/learned/<主题>.md` |
| 有效经验、错误教训、能力缺口 | `<输出根目录>/.agents/memory/learned/<主题>.md` |
| 独立规则 / 提示词 | `<输出根目录>/.agents/rules/<主题>.md`，不得使用 `AGENTS.md` |
| Skill | `<输出根目录>/.agents/skills/<skill-name>/` |
| 脚本 / SQL / 代码片段 | `<输出根目录>/scripts/` |
| CLI | 用户已有 CLI 项目；没有时推荐 `<输出根目录>/tools/cli/` |
| MCP / 工具接口 | 用户已有工具项目；没有时推荐 `<输出根目录>/tools/mcp/` |
| 知识文档 / 索引 | `<输出根目录>/.agents/docs/` |
| 模板 / 示例 / 检查清单 | `<输出根目录>/.agents/templates/` |
| 自动化流程 / 工具配置 | 用户已有自动化项目；没有时推荐 `<输出根目录>/.agents/workflows/` |
| 上下文交接包 | `<输出根目录>/.agents/docs/` 下的全新交接文件 |
| 审查 / 整理 / 验证日志及必要过程产物 | `<输出根目录>/.agents/history/` 下的全新文件或独立运行目录 |
| 冷记忆历史 / 摘要 / 检索记录 | 推荐 `<输出根目录>/.agents/history/memory.db`，仅在宿主提供能力且用户授权时启用 |

同类主题不重复写入多份资产。选定目录只决定输出位置，不授权创建无用文件或改写既有文件。CLI、MCP 和自动化项目的选择不代表授权安装、部署或执行。

配置生效后，其他模板、提示词及 SQL 中的路径仅作结构示例；实际输出必须按已确认类型映射，不静默回退到示例目录。目标类型停用或缺少有效路径时，先确认再生成。冷记忆路径配置不代表数据库或检索接口已存在。
