# 轻整理

> 触发：>10 轮、空闲 30 分钟、跨天、任务完成或会话结束。宿主提供尚未处理的历史及冷记忆读写接口，按历史水位去重；缺少历史或数据库时报告限制，不虚构摘要已回写。
> 路径相对工作空间。既有记忆文件与索引均为只读，只读取用于去重与冲突发现；排除 `.agents/memory/MEMORY.md`、`BOOTSTRAP.md`、`prompts/`、`archive/` 的写入意图。

整理本轮对话历史。只做**轻整理**：写摘要、抽稳定事实、更新索引。**不做跨文件重整**（那是深整理的事）。

**步骤**

1. 读本轮历史
2. 读现有温记忆 + `MEMORY.md` 索引（避免重复、发现冲突）
3. 逐条判定：`summary` 存什么形态 / 要不要提炼进温记忆
4. 写入前读 `.agents/memory/prompts/skillguard.md` 并扫描实际内容；只可新建原先不存在的文件（推荐 `learned/<主题>.md`），不修改既有文件，不回写索引。同一工作空间写入须串行化或加锁

**形态判定**

| 内容特征 | `summary` 里存什么 | 提炼去向 |
|---|---|---|
| 结论清楚、过程不重要 | 提炼后的摘要 | 不提炼，只留冷记忆 |
| 推理链／权衡／失败尝试重要 | 原文摘录 | 不提炼，只留冷记忆 |
| 用户偏好、项目约定、稳定事实 | 提炼后的摘要 | 新建 `learned/<主题>.md`（既有模板文件不追加） |
| 经验、教训、能力缺口 | 提炼后的摘要 | 新建 `learnings/<主题>.md`（既有文件不追加） |
| 一次性过程、无复用价值 | 一行极简记录 | 不提炼 |

判据：以后要问「是什么／结果如何」→ 摘要；要问「为什么这么定／当时怎么试的」→ 原文摘录。

**拿不准时默认留原文摘录。** `history` 无损只保证「查得到」，不保证「会去查」——摘要写歪了就是一颗错误信念的种子，Agent 不会回头核对原文。

**判定晋级**（这是轻整理的活）

读 `search_log`，把语义同属一个主题的查询归一后：

- 累计命中 **≥ 3 次** → 提出温记忆沉淀候选，经用户授权后新建文件；不登记 `MEMORY.md`
- 不足 3 次 → 不动

`search_log` 由检索接口自动写，你不用手动维护。

**写入位置**

| 动作 | 写哪 |
|---|---|
| 摘要 | `summary` 表（宿主提供时） |
| 提炼出的稳定事实 | 新建 `learned/<主题>.md`（经用户授权） |
| 经验／错误／功能请求 | 新建 `learnings/<主题>.md`（既有文件不追加） |
| 索引变更 | 无——索引只读；在答复中报告新文件路径 |

`history` 表**不在回写范围内**——它由主流程每轮同步写。整理只读它，不写它。

**同一天多次整理：合并，不新开。** `summary` 表由宿主维护，同日已有那条就**追加要点**，不新插一行；daily 明细文件由宿主按自身约定追加，Agent 不直接创建或覆盖既有 daily 文件。

**约束**

1. 不删原始历史。判定「无价值」只是不提炼进温记忆
2. 同一条事实不在多个温记忆文件里重复写
3. 稳定事实落温记忆前先过人工确认闸门；后台需要确认的候选交给前台，不自行询问用户或落盘
4. 成功后由宿主推进历史水位；失败保留待处理状态，下一次有效事件重试
