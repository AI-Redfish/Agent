## Markdown 笔记格式规范

### 标题层级

**一级标题就是主题模块**

`#` 代表一个主题，不是「一个文档名把全文包住」。**一篇笔记要有多个一级标题。**

```text
# 初始化模型
# kwargs
# 工具调用
# 结构化输出
```

**二级标题接子项**

```text
# kwargs
## base_url
## headers
## stop
```

**标题名直接写内容名**

写 `# 工具调用`，不写 `# 第一部分`、`# 其他` 这类空壳标题。编号可用可不用，用就全篇统一。

### 段落内的子标签

一级标题内部不再开标题，用 `**加粗标签**` 独占一行，内容另起一段：

```text
**使用**

（内容）

**案例**

（内容）
```

常用标签：`**使用**`、`**案例**`、`**实例**`、`**常见参数**`、`**使用建议**`、`**注意**`

### 间距

- 标题后空 1 行
- 块与块之间空 **2～3 行**
- 代码块、表格前后各空 1 行

### 代码块

- 一律带语言标注：`python`、`text`、`json`、`mermaid`、`powershell`
- 无语言可标时用 `text`，不留裸围栏
- 代码内的注释对齐成列

### 表格

- 表头下必须有分隔行
- 对齐语法用 `| :-- | :-- |`（左对齐）
- 表格前后各空 1 行

### 文字

- 中文与英文、数字之间加空格：「模型 init_chat_model 的用法」
- 强调用 `**加粗**`；补充说明、警告用 `*斜体*`
- `>` 引用块只用于摘要或旁注，不拿它当正文
- 无序列表用 `-`，有序列表用 `1.`

### 骨架示例

```text
# 主题一

**使用**

（内容）

## 子项

（内容）



# 主题二

**案例**

（内容）
```
