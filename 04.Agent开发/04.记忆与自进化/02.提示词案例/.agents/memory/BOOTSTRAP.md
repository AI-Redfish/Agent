# 引导清单

状态：未执行

> 每次会话开始、工作空间切换或上下文重建后检查状态。`未执行` 才做前台引导；先读已有记忆，只问缺项，一次问一组。紧急主任务优先，用户未答时本会话不重复催问。
> 用户确认后，按内容写入 `user-profile.md`、`preferences.md`、`project.md`；写入前读 `prompts/skillguard.md`，写入后同步 `MEMORY.md` 索引。
> 部分完成仍保留 `未执行`。必要信息收集完成且已落盘、索引同步后，才改成「状态：已完成 YYYY-MM-DD」。保留文件作为完成凭据，之后不再执行；用户明确要求重新初始化时才重置状态。
