# 引导清单

> 每次会话开始、工作空间切换或上下文重建后按本清单检查。先读已有记忆，只问缺项，一次问一组。紧急主任务优先，用户未答时本会话不重复催问。
> 本文件与 `user-profile.md`、`preferences.md`、`project.md` 均为只读模板，不回写、不改状态。用户确认的答案按 `AGENTS.md` 零节写入原先不存在的新文件（推荐 `learned/` 下主题文件），或仅在对话中记录；写入前读 `prompts/skillguard.md`。
> 引导完成的判断基于本次会话记录；用户明确要求重新初始化时重新走一遍清单。

## 关于用户
- 你怎么称呼？
- 技术背景和常用技术栈？
- 希望我怎么跟你说话（详细 / 精简 / 先给结论）？
- 有什么是你明确不想要的？

## 关于这个工作空间
- 这个项目是做什么的？
- 用什么包管理器、怎么构建、怎么跑测试？
- 有哪些必须遵守的约定？
- 有没有正在踩的坑？
