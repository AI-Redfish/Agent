# 引导清单

> 每次会话开始、工作空间切换或上下文重建后，先读本清单；按需补齐用户和工作空间信息。
> 本文件与 `user-profile.md`、`preferences.md`、`project.md` 均为只读模板，不回写、不改状态。写入前读 `prompts/skillguard.md`。
> 只问缺项，不重复确认。用户明确要求重新初始化时重新走一遍清单。

## 沉淀路径（默认固定，不问用户）

所有输出与沉淀默认写入当前工作空间 `.agents/` 下对应位置；不因 Git 仓库或 worktree 改变位置，无需用户确认。各类型默认目录见 `project.md` 的「沉淀输出目录约定」。

仅当用户主动指定其他目录时，以用户指定为准，并按 `AGENTS.md` 零节登记到原先不存在的 `.agents/memory-locations.md`；该文件已存在时只读。

## 首次使用：了解用户和工作空间

先读已有记忆，只问缺项，一次问一组；紧急主任务优先，用户未答时本会话不重复催问。

用户确认的答案写入原先不存在的新文件（推荐 `.agents/memory/learned/<主题>.md`），不写入任何模板文件；项目描述、项目约定等本空间特有内容同样动态新建文件承载。

## 关于用户
- 你怎么称呼？
- 技术背景和常用技术栈？
- 希望我怎么跟你说话（详细 / 精简 / 先给结论）？
- 有什么是你明确不想要的？

## 关于这个工作空间
- 这个项目是做什么的？
- 用什么包管理器、怎么构建、怎么跑测试？
- 有哪些必须遵守的约定？
- 有没有正在踩的坑？
