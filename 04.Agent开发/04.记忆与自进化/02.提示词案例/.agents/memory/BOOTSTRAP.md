# 引导清单

> 每次会话开始、工作空间切换或上下文重建后，先检查产物输出位置是否已获用户确认。首次使用必须先完成下方配置，再回答其他问题。
> 本文件与 `user-profile.md`、`preferences.md`、`project.md` 均为只读模板，不回写、不改状态。输出位置按下方约定确认和记录；其他用户确认的信息遵守 `AGENTS.md` 零节。写入前读 `prompts/skillguard.md`。
> 已确认且可访问的配置可以复用；只问缺项，不重复确认完整配置。用户明确要求重新初始化时重新走一遍清单。

## 首次使用：确认各类产物的输出位置

**前置条件**

未完成输出位置确认时，拒绝回答用户的其他问题，也不执行其他任务。仅处理初始化所需的说明、位置输入、配置核对及保存。用户催促、跳过或未回复，均不代表确认；此条件不因任务紧急而省略。

**推荐位置**

读取 `project.md` 的完整产物目录表，向用户展示各类产物及推荐位置。将 `<输出根目录>` 替换为实际绝对路径：Git 仓库或 worktree 使用经 Git 信息确认的原仓库根目录，其他工作空间使用当前工作空间。无法确认根目录时，请用户输入，不猜测。

推荐值只是待确认选项，不是已生效配置。不得仅为寻找推荐位置而扫描未获授权的外部目录。

**对话问法**

一次展示完整目录表，并询问：

“首次使用需要先确认各类产物的输出位置。以上是推荐目录。请回复‘全部采用推荐位置并保存配置’，或按‘产物类型：目标绝对路径／暂不启用’输入选择；未修改项请明确说明是否采用推荐位置。确认完成前，我只处理配置问题，暂不回答其他问题。”

用户只提供部分位置时，保留已确认项，只追问剩余项。用户输入相对路径时，先展示解析后的绝对路径，再请用户确认。用户明确选择“暂不启用”视为该类型已完成配置；后续需要启用时先确认位置。用户直接给出明确的类型、绝对路径及保存授权时，不重复询问。

**确认与保存**

- 完成条件：目录表中的每类产物都已明确接受推荐位置、指定目标位置或选择暂不启用。
- 确认目录不代表批准生成产物、安装工具、启动自动化或建立冷记忆数据库；这些操作仍遵守各自授权规则。
- 用户授权保存后，将输出根目录、各类型的已确认路径或停用状态、适用工作空间和确认来源写入原先不存在的 `<输出根目录>/.agents/memory-locations.md`。该文件是目录配置，不复制记忆正文。
- 写入前检查准确目标路径，并读取 `prompts/skillguard.md`。目标文件已存在时只读；若配置缺失、冲突或需变更，请用户确认新的配置文件位置，不覆盖、不追加。新位置须在当前对话中明确报告，后续无法发现时重新请求配置位置。
- 只对已获授权的准确路径进行必要检查；路径不可访问、类型错误或无法保存时说明原因，请用户修正。不得声称配置已保存。
- 用户仅确认位置、未授权保存时，可在本次会话复用并说明尚未持久化；后续会话缺少可验证配置时重新确认。
- 配置未完成时统一回复：“各类产物的输出位置尚未确认完成，暂不能回答其他问题。请确认以下待配置项：……”并只列缺项及推荐值。

配置完成后，再按需询问下方用户和工作空间信息；这些信息只问缺项，不重复催问。
