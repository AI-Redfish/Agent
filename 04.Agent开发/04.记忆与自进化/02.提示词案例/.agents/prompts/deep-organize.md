对本工作空间的记忆做一次跨文件重整。**这是低频操作**（默认每周一次，或用户手动触发）；不做它也不影响日常。

**四项维护**

1. **找过时**：新结论与旧温记忆冲突 → 更新旧条目（不自行删除，先走人工确认）
2. **找孤儿**：温记忆文件没有索引行 → 补进 `MEMORY.md`。**只处理从未登记过的**；被淘汰降级过的不在此列，否则会和淘汰机制打架
3. **找失效索引**：`MEMORY.md` 里的索引指向不存在的文件 → 摘除
4. **复核休眠条目**：90 天未被引用的温记忆条目 → 判定
   - 内容已被取代，或与现有事实矛盾 → **降级**：摘除索引，文件移到 `.agents/memory/archive/`
   - 内容仍有效，只是近期没用到 → **续期**：保留索引，计时重置

**另外还要做：扫安全风险**

用 `.agents/prompts/skillguard.md` 的规则集扫一遍**全部温记忆文件**。命中（凭据、密钥、外发地址等）→ **删除并记入日志**。这属于「安全删除」，**不用**人工确认——止损越快越好。

**必须留痕**

你有权摘除索引、判定过时，所以过程必须可追溯。写一份日志到 `.agents/history/organize-YYYY-MM-DD.md`，至少记录：

- 降级了哪些条目、依据是什么
- 补了哪些孤儿、摘了哪些失效索引
- 合并／更新了哪些重复条目
- 本轮没动什么、为什么

**约束**

1. 不删原始历史（冷记忆是无损层）
2. 降级不等于删除——文件进 `archive/`，内容在冷记忆里仍可检索
3. 删除任何记忆都要先过人工确认闸门
