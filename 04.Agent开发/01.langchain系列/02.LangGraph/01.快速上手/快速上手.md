# LangGraph 是什么

LangGraph 是 LangChain 生态中面向 Agent 和复杂 LLM 工作流的底层编排框架。

它不是简单的"链式调用工具"，而是用**“图”**来表达流程：节点负责执行逻辑，边负责控制流，状态负责在节点之间传递信息。



适合使用 LangGraph 的场景：

- **多步骤 Agent**：需要在不同节点之间传递状态，且状态会随执行不断演进。
- **流程中存在条件分支、循环、重试或人工审批**：这些控制流逻辑在 LangGraph 中可以通过边和节点天然表达。
- **需要持久化执行状态，支持中断后继续运行**：LangGraph 原生支持 checkpoint 机制，可以实现断点续跑。
- **需要长期维护的生产级 Agent**：可观测性、可调试性和可测试性更好，适合持续迭代。
- **需要多 Agent 协作、子图拆分、工具调用和可观测性**：LangGraph 支持子图嵌套和层次化编排。



不一定需要 LangGraph 的场景：

- **一次简单 LLM 调用**：直接 `model.invoke()` 即可。
- **单轮问答**：无状态、无分支，无需引入编排框架。
- **只有固定顺序的两三步脚本**：`RunnableSequence` 或 `chain` 即可满足。
- **没有状态管理、恢复、分支、循环需求的轻量任务**：避免过度设计，保持简单。

## 最小概念

快速上手只需要先记住 5 个概念：

| 概念 | 含义 |
|---|---|
| `StateGraph` | 用状态图描述工作流 |
| `State` | 节点之间共享的数据结构 |
| `Node` | 一个处理函数，输入 state，返回 state 更新 |
| `Edge` | 从一个节点走到另一个节点 |
| `compile()` | 把图编译成可运行对象 |

# 最小 StateGraph

## 代码示例

```python
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END


class State(TypedDict):
    topic: str
    joke: str


def generate_joke(state: State):
    return {"joke": f"这是一个关于 {state['topic']} 的笑话。"}


builder = StateGraph(State)
builder.add_node("generate_joke", generate_joke)
builder.add_edge(START, "generate_joke")
builder.add_edge("generate_joke", END)

graph = builder.compile()
result = graph.invoke({"topic": "LangGraph"})

print(result)

# 获取图的mermaid图表示
raw_mermaid = graph.get_graph().draw_mermaid()
print(raw_mermaid)
```

输出大致是：

```python
{'topic': 'LangGraph', 'joke': '这是一个关于 LangGraph 的笑话。'}
---
config:
  flowchart:
    curve: linear
---
graph TD;
        __start__([<p>__start__</p>]):::first
        generate_joke(generate_joke)
        __end__([<p>__end__</p>]):::last
        __start__ --> generate_joke;
        generate_joke --> __end__;
        classDef default fill:#f2f0ff,line-height:1.2
        classDef first fill-opacity:0
        classDef last fill:#bfb6fc
```

## 执行过程

执行过程可以理解为：

```text
START
  -> generate_joke
  -> END
```

节点 `generate_joke` 接收当前状态：

```python
{"topic": "LangGraph"}
```

节点返回状态增量：

```python
{"joke": "这是一个关于 LangGraph 的笑话。"}
```

LangGraph 把增量合并回 state，得到最终结果。

# 聊天 Agent 示例

```python
import os

from dotenv import load_dotenv
from langchain.chat_models import init_chat_model
from langchain_core.messages import HumanMessage, SystemMessage,AnyMessage,ToolMessage
from langchain.tools import tool


from typing_extensions import TypedDict, Annotated
import operator

from typing import Literal
from langgraph.graph import StateGraph, START, END
from langgraph.prebuilt import ToolNode



load_dotenv()

api_key = os.getenv("OPENAI_API_KEY")
model_name = os.getenv("OPENAI_MODEL")  
base_url = os.getenv("OPENAI_BASE_URL")  
model_provider = os.getenv("MODEL_PROVIDER")  

# 创建模型（使用 init_chat_model）
model = init_chat_model(
    model=model_name,
    model_provider=model_provider,
    api_key=api_key,
    base_url=base_url,
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2
)

# Define tools
@tool
def multiply(a: int, b: int) -> int:
    """Multiply `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a * b


@tool
def add(a: int, b: int) -> int:
    """Adds `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a + b


@tool
def divide(a: int, b: int) -> float:
    """Divide `a` and `b`.

    Args:
        a: First int
        b: Second int
    """
    return a / b


# Augment the LLM with tools
tools = [add, multiply, divide]
tools_by_name = {tool.name: tool for tool in tools}
model_with_tools = model.bind_tools(tools)




class MessagesState(TypedDict):
    # 告诉 LangGraph：当多个节点返回 messages 时，使用 operator.add 来合并
    messages: Annotated[list[AnyMessage], operator.add]
    llm_calls: int




def should_continue(state: MessagesState) -> Literal["tool_node", END]:
    """Decide if we should continue the loop or stop based upon whether the LLM made a tool call"""

    messages = state["messages"]
    last_message = messages[-1]

    # If the LLM makes a tool call, then perform an action
    if last_message.tool_calls:
        return "tool_node"

    # Otherwise, we stop (reply to the user)
    return END


# todo: 感觉有问题
def llm_call(state: dict):
    """LLM decides whether to call a tool or not"""

    return {
        "messages": [
            model_with_tools.invoke(
                [
                    SystemMessage(
                        content="You are a helpful assistant tasked with performing arithmetic on a set of inputs."
                    )
                ]
                + state["messages"]
            )
        ],
        "llm_calls": state.get('llm_calls', 0) + 1
    }


# Build workflow
agent_builder = StateGraph(MessagesState)

# Add nodes
agent_builder.add_node("llm_call", llm_call)
agent_builder.add_node("tool_node",  ToolNode(tools))

# Add edges to connect nodes
agent_builder.add_edge(START, "llm_call")
agent_builder.add_conditional_edges(
    "llm_call",
    should_continue,
    ["tool_node", END]
)
agent_builder.add_edge("tool_node", "llm_call")

# Compile the agent
agent = agent_builder.compile()


messages = [HumanMessage(content="Add 3 and 4.")]
messages = agent.invoke({"messages": messages})
for m in messages["messages"]:
    m.pretty_print()
```



# 修改 state

不推荐：

```python
def node(state):
    state["count"] += 1
    return state
```

推荐：

```python
def node(state):
    return {"count": state["count"] + 1}
```

原因：节点应该返回状态更新，让 LangGraph 统一负责合并。
