

# invoke()

`invoke()` 同步执行 Agent，直到拿到最终结果。


**使用**

```python
result = agent.invoke(
    {"messages": [{"role": "user", "content": "帮我查一下北京天气"}]}
)

print(result["messages"][-1].content)
```


**适合**

- 命令行脚本
- 简单后端接口
- 不需要实时展示过程的任务


# ainvoke()

`ainvoke()` 是异步版本的 `invoke()`。

适合 FastAPI、异步 Web 服务等环境。


**使用**

```python
result = await agent.ainvoke(
    {"messages": [{"role": "user", "content": "帮我查一下北京天气"}]}
)

print(result["messages"][-1].content)
```


# stream()

可以一边执行一边把消息、步骤或自定义事件流出来，适合调试和前端展示。

stream() 支持多种 stream_mode，每种提供不同粒度的信息。



stream_mode 可以组合使用，如 stream_mode=["updates", "custom", "messages"]。但过多的模式会增加流中的事件量，建议按需选择。



## **messages**

这是最细粒度的流式模式，每个 chunk 对应一个 Token。

逐 Token 的消息流  前端流式展示 AI 打字效果。

```python
print("=== stream_mode='messages'（流式打字效果）===\n")
for msg_chunk, metadata in agent.stream(
    {"messages": [HumanMessage(content="用一句话介绍菜鸟教程 RUNOOB")]},
    stream_mode="messages",
):
    # msg_chunk 是 AIMessageChunk，每个只包含一个 Token
    if hasattr(msg_chunk, 'content') and msg_chunk.content:
        print(msg_chunk.content, end="", flush=True)
print()
```

**metadata**

```
print("查看 metadata 信息：\n")
for msg_chunk, metadata in agent.stream(
    {"messages": [HumanMessage(content="你好，介绍一下你自己")]},
    stream_mode="messages",
):
    if msg_chunk.content and len(msg_chunk.content) > 5:
        print(f"内容: {msg_chunk.content}")
        print(f"来源节点: {metadata.get('langgraph_node')}")
        print(f"消息类型: {type(msg_chunk).__name__}")
        break  # 只看第一个有意义的 chunk
        
        
输出结果：
查看 metadata 信息：

来源节点: model
消息类型: AIMessageChunk
```







## **updates**

这个模式在构建需要显示"思考过程"的界面时非常有用。

与 values模式返回完整的图状态不同，updates模式只返回每个节点产生的更新部分（即当前节点对状态做了哪些修改）。

```python
from dotenv import load_dotenv
load_dotenv()

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage
import os
from langchain.tools import tool, InjectedState
import json


load_dotenv()

# 2. 定义多个实用工具
@tool
def get_weather(city: str) -> str:
    """获取指定城市的天气信息"""
    weather_data = {
        "北京": "晴天，28°C，空气质量良",
        "上海": "多云转阴，26°C，可能有小雨",
        "深圳": "晴天，32°C，注意防晒",
        "杭州": "阴天，24°C，适合外出",
    }
    return weather_data.get(city, f"抱歉，未找到{city}的天气数据")

@tool
def calculate(expression: str) -> str:
    """计算数学表达式，如 '2+3*4'"""
    result = eval(expression)
    return f"{expression} = {result}"

@tool
def get_current_time() -> str:
    """获取当前日期和时间"""
    from datetime import datetime
    now = datetime.now()
    return f"当前时间: {now.strftime('%Y年%m月%d日 %H:%M:%S')}"

api_key = os.getenv("API_KEY")
model_name = os.getenv("MODEL")  
base_url = os.getenv("BASE_URL")  
model_provider = os.getenv("MODEL_PROVIDER")  

headers = {
    "User-Agent": "Codex (OpenAI-Codex; +https://openai.com/codex) Python/3.12",
    "X-Client-Type": "codex"     
}

model = init_chat_model(
    model=model_name,
    model_provider=model_provider,
    api_key=api_key,
    base_url=base_url,
    default_headers=headers
)

agent = create_agent(
    model=model,
    tools = [get_weather, calculate, get_current_time]
)

step = 0
final_answer = ""
for update in agent.stream(
    {"messages": [HumanMessage(content="帮我查一下深圳天气，然后计算 25+17*3 等于多少")]},
    stream_mode="updates",
):
    step += 1
    print(f"\n📌 步骤 {step}:")
    
    # 遍历每个节点的更新
    for node_name, node_update in update.items():
        print(f"  🔹 执行节点: {node_name}")
        
        # 检查是否有新消息
        if "messages" in node_update:
            messages = node_update["messages"]
            for msg in messages:
                # 获取消息类型
                msg_type = getattr(msg, "type", "unknown")
                
                # 处理不同类型的消息
                if msg_type == "ai":
                    content = msg.content if msg.content else "[正在思考...]"
                    print(f"    💬 AI思考: {content[:150]}")
                    
                    # 检查是否有工具调用
                    if hasattr(msg, "tool_calls") and msg.tool_calls:
                        print(f"    🔧 准备调用工具:")
                        for tool_call in msg.tool_calls:
                            print(f"       - 工具: {tool_call['name']}")
                            print(f"         参数: {json.dumps(tool_call['args'], ensure_ascii=False)}")
                    
                elif msg_type == "tool":
                    print(f"    🛠️  工具返回: {msg.content[:200]}")
                    
                elif msg_type == "human":
                    print(f"    👤 用户消息: {msg.content}")
                
                # 保存最终答案（最后一条AI消息）
                if msg_type == "ai" and msg.content and not hasattr(msg, "tool_calls"):
                    final_answer = msg.content

print("\n" + "=" * 60)
print(f"\n✅ 最终答案:\n{final_answer}")
```



## **values**

输出每个步骤之后完整的图状态（state）。

也就是说，每当图执行完一个节点（node），就会把当前所有的状态值（包括消息历史、中间变量等）作为一个整体返回。

```python
for step in agent.stream(
    {"messages": [{"role": "user", "content": "帮我查一下北京天气"}]},
    stream_mode="values",
):
    print(step["messages"][-1].content)
```





## custom

通过 Middleware 的 runtime.stream_writer()，你可以向流中发送自定义事件。

```
from langchain.agents.middleware import before_model, after_model


@before_model
def notify_before(state, runtime):
    """在模型调用前发送自定义事件"""
    runtime.stream_writer({
        "type": "status",
        "message": "正在思考...",
    })
    return None


@after_model
def notify_after(state, runtime):
    """在模型调用后发送自定义事件"""
    last_msg = state["messages"][-1] if state.get("messages") else None
    has_tools = hasattr(last_msg, 'tool_calls') and last_msg.tool_calls

    if has_tools:
        tool_names = [tc['name'] for tc in last_msg.tool_calls]
        runtime.stream_writer({
            "type": "status",
            "message": f"正在调用工具: {', '.join(tool_names)}...",
        })
    else:
        runtime.stream_writer({
            "type": "status",
            "message": "回答已完成",
        })
    return None


agent = create_agent(
    model=init_chat_model("deepseek:deepseek-v4-flash", temperature=0),
    tools=[search_course],
    middleware=[notify_before, notify_after],
    system_prompt="你是菜鸟教程 RUNOOB 的课程顾问。",
)

# 使用 stream_mode=["updates", "custom"] 同时接收两种事件
print("=== 混合流式输出 ===\n")
for mode, chunk in agent.stream(
    {"messages": [HumanMessage(content="查一下 Python 课程")]},
    stream_mode=["updates", "custom"],
):
    if mode == "custom":
        print(f"[自定义事件] 状态: {chunk['message']}")
    elif mode == "updates":
        for node_name, update in chunk.items():
            if "messages" in update:
                for msg in update["messages"]:
                    if msg.type == "ai" and msg.content:
                        print(f"[回复] {msg.content}")
                        
                        
                        
                        
输出：
=== 混合流式输出 ===

[自定义事件] 状态: 正在思考...
[自定义事件] 状态: 正在调用工具: search_course...
[回复] 菜鸟教程 RUNOOB 中有 Python3 基础教程，共30章，学习时长约20小时。
[自定义事件] 状态: 正在思考...
[自定义事件] 状态: 回答已完成
```







# astream()

`astream()` 是异步版本的 `stream()`。

适合 WebSocket、SSE 这类需要持续推送内容的场景。


**使用**

```python
import asyncio


async def stream_agent():
    """异步流式运行 Agent"""
    agent = create_agent(
        model=init_chat_model("deepseek:deepseek-v4-flash"),
        system_prompt="你是菜鸟教程 RUNOOB 的助手。",
    )

    full_response = ""
    async for msg_chunk, metadata in agent.astream(
        {"messages": [HumanMessage(content="一句话介绍菜鸟教程")]},
        stream_mode="messages",
    ):
        if msg_chunk.content:
            full_response += msg_chunk.content
            print(msg_chunk.content, end="", flush=True)

    print(f"\n\n完整回复长度: {len(full_response)} 字")


# 运行异步函数
asyncio.run(stream_agent())
```





# get_state()

`get_state()` 用来读取指定会话线程的当前状态。

通常需要和 `checkpointer`、`thread_id` 一起使用。


**使用**

```python
config = {"configurable": {"thread_id": "user-001"}}

agent.invoke(
    {"messages": [{"role": "user", "content": "我叫小明"}]},
    config=config,
)

state = agent.get_state(config)
print(state.values["messages"][-1].content)
```


# update_state()

`update_state()` 用来手动修改指定会话线程的状态。

适合人工修正、恢复对话、插入外部状态。

**使用**

```python
config = {"configurable": {"thread_id": "user-001"}}

agent.update_state(
    config,
    {
        "messages": [
            {"role": "user", "content": "我喜欢 Python"}
        ],
        "user_level": "入门",
    },
)

state = agent.get_state(config)
print(state.values)
```


**注意**

- `get_state()` 和 `update_state()` 依赖可恢复状态，通常需要配置 `checkpointer`。
- `invoke()` / `ainvoke()` 适合拿最终结果。
- `stream()` / `astream()` 适合观察执行过程或推送到前端。







# config

通过 config 传入 thread_id 来管理对话线程。

```
# config 用于传递运行时配置
# thread_id 用于区分不同的对话线程
config = {"configurable": {"thread_id": "conversation-001"}}

# invoke 方式
result = agent.invoke(
    {"messages": [HumanMessage(content="你好")]},
    config=config,
)

# stream 方式也支持 config
for chunk in agent.stream(
    {"messages": [HumanMessage(content="你好")]},
    config=config,
    stream_mode="updates",
):
    print(chunk)
```
