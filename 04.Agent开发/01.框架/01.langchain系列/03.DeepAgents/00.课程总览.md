# DeepAgents 实战 — 课程总览

## 课程信息

- **课程**：《Deep Agents 实战 — 从零构建生产级 AI Agent 的完整指南》（Datawhale 开源课程，共 19 章）
- **作者**：沧海九粟（LangChain 官方大使）
- **官网**：https://datawhalechina.github.io/deepagents-in-action/
- **GitHub**：https://github.com/datawhalechina/deepagents-in-action
- **基线版本**：Deep Agents 0.7（课程起步于 0.5）
- **官方文档**：[Python 版](https://docs.langchain.org.cn/oss/python/deepagents/overview) · [JS 版](https://docs.langchain.org.cn/oss/javascript/deepagents/overview)
- **视频合集**：[B 站合集](https://space.bilibili.com/28357052/lists/7757577?type=season)（Lec 01–20）

**技术定位**：Deep Agents 是构建在 LangChain（Framework）+ LangGraph（Runtime）之上的 **Agent Harness**——预置虚拟文件系统、任务规划、子 Agent 委派、长期记忆等生产级能力，核心理念是 Context Engineering（上下文工程）。
