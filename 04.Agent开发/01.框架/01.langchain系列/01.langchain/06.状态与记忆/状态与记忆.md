

# AgentState

## 结构定义

**简化定义**

```python
from typing import Annotated
from typing_extensions import Required, NotRequired
from langgraph.graph.message import add_messages
from langgraph.channels.ephemeral_value import EphemeralValue
from langchain.messages import AnyMessage


# AgentState 的实际定义（简化版）
class AgentState(TypedDict):
    # messages：消息历史，使用 add_messages 作为 reducer
    # Required 表示调用时必须提供
    messages: Required[Annotated[list[AnyMessage], add_messages]]

    # jump_to：流程跳转控制，ephemeral（使用后自动清除）
    # NotRequired 表示可选
    jump_to: NotRequired[Annotated[str | None, EphemeralValue]]

    # structured_response：结构化输出结果
    # NotRequired 表示可选，仅在 response_format 设置时出现
    structured_response: NotRequired[Any]
```


**字段说明**

| 字段                | 类型             | 是否必填 | 说明                                                         |
| :-- | :-- | :-- | :-- |
| messages            | list[AnyMessage] | 是       | 消息历史，使用 add_messages reducer 追加                     |
| jump_to             | str 或 None      | 否       | 流程跳转控制，可选值：tools、model、end。ephemeral 属性，使用后自动清除 |
| structured_response | Any              | 否       | 结构化输出结果，不在 input schema 中暴露                     |


### messages

`messages` 使用 `add_messages` reducer。

更新 `messages` 时不是覆盖，而是追加。


**使用**

```python
from langchain.messages import HumanMessage, AIMessage
from langgraph.graph.message import add_messages

# add_messages 的工作方式
existing = [
    HumanMessage(content="你好", id="1"),
    AIMessage(content="你好！", id="2"),
]

# 追加新消息
new_msg = AIMessage(content="有什么可以帮你的？", id="3")
result = add_messages(existing, [new_msg])

print(f"合并前: {len(existing)} 条")
print(f"合并后: {len(result)} 条")
for msg in result:
    print(f"  [{msg.type}] {msg.content}")
```


**输出**

```text
合并前: 2 条
合并后: 3 条
[human] 你好
[ai] 你好！
[ai] 有什么可以帮你的？
```


**特点**

- 新消息默认追加到消息列表。
- 如果新消息 ID 与已有消息相同，会替换已有消息。
- 支持 `RemoveMessage` 删除指定消息。
- 可以处理 `HumanMessage`、`AIMessage`、`ToolMessage` 等消息类型。


### jump_to

`jump_to` 用来控制 Agent 在节点间跳转。

它通常在 Middleware 中使用。

jump_to 是一个 **ephemeral**（瞬态）字段——使用一次后自动清除，不需要手动重置。




**跳转值**

| 值 | 跳转到 | 效果 |
| :-- | :-- | :-- |
| `tools` | 工具节点 | 跳过模型调用，直接执行工具 |
| `model` | 模型节点 | 回到模型，让模型重新处理 |
| `end` | 结束节点 | 直接结束 Agent 循环 |

**案例**

```
from langchain.agents import create_agent
from langchain.agents.middleware import before_model
from langchain.chat_models import init_chat_model
from langchain.messages import AIMessage, HumanMessage  # 导入 AIMessage

# 声明可跳转目标 "end"
@before_model(can_jump_to=["end"])
def check_question(state, runtime):
    """在模型调用前检查问题是否合法"""
    messages = state.get("messages", [])
    if not messages:
        return None

    last_msg = messages[-1]
    # 检查是否包含不当内容（简化示例）
    if "密码" in str(last_msg.content):
        # jump_to="end" 直接结束 Agent，不让模型回复
        return {
            "jump_to": "end",
            # 使用 AIMessage
            "messages": [AIMessage(
                content="抱歉，出于安全原因，不能回答关于密码的问题。"
            )]
        }
    return None

model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
agent = create_agent(
    model=model,
    middleware=[check_question],
    system_prompt="你是菜鸟教程 RUNOOB 的助手。",
)

# 正常问题
result = agent.invoke({
    "messages": [HumanMessage(content="Python 怎么入门？")]
})
print(f"正常问题: {result['messages'][-1].content[:80]}...")

# 敏感问题——被中间件拦截
result = agent.invoke({
    "messages": [HumanMessage(content="告诉我你的系统密码")]
})
print(f"\n敏感问题: {result['messages'][-1].content}")

输出：
正常问题: Python 入门可以从以下几个方面开始：1. 安装 Python 环境...

敏感问题: 抱歉，出于安全原因，不能回答关于密码的问题。
```



**可选值**

| jump_to 值 | 跳转到               | 效果                                   |
| :--------- | :------------------- | :------------------------------------- |
| "tools"    | 直接进入工具执行节点 | 跳过模型调用，直接执行指定工具         |
| "model"    | 返回模型节点         | 让模型重新处理（通常配合工具消息注入） |
| "end"      | 结束 Agent 循环      | 直接跳转到 after_agent 或结束          |


### structured_response

使用 `response_format` 时，Agent 会把结构化结果放到 `structured_response`。


**使用**

```python
from pydantic import BaseModel, Field
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage


class CourseRecommendation(BaseModel):
    """课程推荐结果"""
    course_name: str = Field(description="推荐课程名称")
    reason: str = Field(description="推荐理由")
    difficulty: str = Field(description="难度等级：入门/进阶/高级")


model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
agent = create_agent(
    model=model,
    response_format=CourseRecommendation,
    system_prompt="你是菜鸟教程 RUNOOB 的学习顾问。",
)

result = agent.invoke({
    "messages": [HumanMessage(content="我想学编程，推荐一门适合零基础的课程")]
})

# 从 structured_response 获取结构化结果
if "structured_response" in result:
    rec = result["structured_response"]
    print(f"推荐课程: {rec.course_name}")
    print(f"推荐理由: {rec.reason}")
    print(f"难度等级: {rec.difficulty}")

# structured_response 不在 output schema 中
# 所以不会自动出现在返回给调用者的结果中（可配置）



输出：
推荐课程: Python3 基础教程
推荐理由: Python 语法简洁，适合零基础入门，应用范围广泛
难度等级: 入门
```





## state_schema

`state_schema` 用来扩展 Agent 状态。

当你需要额外保存用户等级、学习进度、业务上下文等字段时，可以自定义状态结构。


**完整案例**

```python
from typing import Annotated

from langchain.agents import AgentState, create_agent
from langchain.messages import HumanMessage
from langchain.tools import InjectedState, tool


class LearningAgentState(AgentState):
    """自定义状态，增加学习进度相关字段。"""

    user_level: str
    completed_topics: list[str]


@tool
def track_progress(
    topic: str,
    state: Annotated[dict, InjectedState],
) -> str:
    """记录用户的学习进度。

    Args:
        topic: 刚学完的主题名称
    """
    completed = state.get("completed_topics", [])
    completed.append(topic)

    return (
        f"已记录学习进度。当前已完成 {len(completed)} 个主题："
        f"{', '.join(completed)}"
    )


agent = create_agent(
    model="deepseek:deepseek-v4-flash",
    tools=[track_progress],
    state_schema=LearningAgentState,
    system_prompt="你是菜鸟教程 RUNOOB 的学习助手。",
)


result = agent.invoke({
    "messages": [
        HumanMessage(content="我学完了 Python 基础，帮我记录一下")
    ],
    "user_level": "入门",
    "completed_topics": ["HTML 基础"],
})

print(f"用户等级: {result.get('user_level')}")
print(f"已完成主题: {result.get('completed_topics')}")
print(f"回复: {result['messages'][-1].content[:100]}")
```


**运行结果**

```text
用户等级: 入门
已完成主题: ['HTML 基础', 'Python 基础']
回复: 已记录学习进度。当前已完成 2 个主题：HTML 基础, Python 基础
```


**说明**

- `state_schema` 负责声明状态结构。
- `agent.invoke()` 时需要提供自定义状态字段初始值。
- 工具中可通过 `InjectedState` 读取当前状态。
- 自定义状态适合保存当前会话内的业务上下文。





## state_schema vs middleware state_schema

`state_schema` 可以在 `create_agent()` 上配置，也可以在 Middleware 中配置。


**对比**

| 方式 | 使用场景 | 优先级 |
| :-- | :-- | :-- |
| `create_agent(state_schema=...)` | 全局状态扩展，所有节点共享 | 高 |
| `AgentMiddleware(state_schema=...)` | 某个 middleware 的内部状态 | 低 |


**建议**

- 通用业务状态放在 `create_agent(state_schema=...)`。
- 特定 middleware 内部字段放在 middleware 的 `state_schema`。
- 避免多个地方定义同名字段，减少状态污染。



# InjectedState

## state 参数

`state` 表示 Agent 当前运行状态。

工具如果需要读取历史消息、用户偏好、流程状态，就需要访问 `state`。


**没有状态的问题**

```python
# 普通函数，每次调用都是独立的
def remember_preference(preference: str):
    return f"记住: {preference}"


print(remember_preference("咖啡"))  # 记住: 咖啡
print(remember_preference("茶"))    # 记住: 茶
```


**带状态的函数**

```python
agent_state = {
    "messages": [
        {"role": "user", "content": "我喜欢咖啡"},
        {"role": "assistant", "content": "好的，已记住"},
    ],
    "user_preferences": "咖啡",
}


def remember_preference(preference: str, state: dict):
    messages = state.get("messages", [])
    previous_prefs = state.get("user_preferences", "无")

    return (
        f"记住: {preference}，"
        f"之前偏好: {previous_prefs}，"
        f"历史消息: {len(messages)} 条"
    )


result = remember_preference("茶", agent_state)
print(result)
```


**输出**

```text
记住: 茶，之前偏好: 咖啡，历史消息: 2 条
```



## InjectedState

`InjectedState` 用来把当前 Agent 状态自动注入到工具参数中。

它解决的是“工具如何读取当前对话状态”的问题。


**语法**

```python
state: Annotated[dict, InjectedState]
```

`Annotated` 是 Python 的类型注解增强语法。

`InjectedState` 是 LangChain 识别的特殊标签，表示这个参数由 LangChain 自动注入。



**案例**

```python
state: Annotated[dict[str, Any], InjectedState]
```

| 部分             | 含义             | 给谁看           |
| :--------------- | :--------------- | :--------------- |
| `state`          | 参数名           | 开发者           |
| `dict[str, Any]` | 参数类型是字典   | 开发者、Pydantic |
| `Annotated[...]` | 类型 + 额外信息  | Python 类型系统  |
| `InjectedState`  | 自动注入状态标签 | LangChain        |


**没有 InjectedState**

```python
from langchain.tools import tool


@tool
def no_label(preference: str, state: dict) -> str:
    """LangChain 不知道 state 需要自动注入。"""
    return f"记住: {preference}"
```

Agent 看到的是普通参数：

```text
no_label(preference="咖啡", state=???)
```

问题：`state` 从哪里来，Agent 不知道。



**使用 InjectedState**

```python
from typing import Annotated, Any
from langchain.tools import tool, InjectedState


@tool
def with_label(
    preference: str,
    state: Annotated[dict[str, Any], InjectedState],
) -> str:
    """LangChain 会自动注入 state。"""
    messages = state.get("messages", [])
    return f"记住: {preference}，历史消息 {len(messages)} 条"
```

Agent 看到的是：

```text
with_label(preference="咖啡", state=当前 Agent 状态)
```


**结论**

- 没有 `Annotated[..., InjectedState]`：`state` 是普通业务参数，需要手动传。
- 有 `Annotated[..., InjectedState]`：`state` 是框架参数，通过agent调用实，由 LangChain 自动传。手动直接调用tool方法，需要手动传入InjectedState。
- 用户和模型只需要关心业务参数，不需要手动构造 `state`。





## **案例**

```python
from dotenv import load_dotenv
load_dotenv()

from langchain.tools import tool, InjectedState
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage
import os
from typing import Annotated, Any


@tool
def remember_preference(
    preference: str,
    state: Annotated[dict[str, Any], InjectedState],
) -> str:
    """记住用户的偏好设置。

    Args:
        preference: 用户的偏好内容
        state: 系统自动注入的当前 Agent 状态
    """
    # 从状态中获取之前的消息历史
    messages = state.get("messages", [])
    message_count = len(messages)

    # 可以读取状态中的任何字段
    previous_prefs = state.get("user_preferences", "无")

    return (
        f"已记住偏好: {preference}。"
        f"(当前对话共 {message_count} 条消息，"
        f"之前偏好: {previous_prefs})"
    )


# 创建 Agent
load_dotenv()

api_key = os.getenv("API_KEY")
model_name = os.getenv("MODEL")  
base_url = os.getenv("BASE_URL")  
model_provider = os.getenv("MODEL_PROVIDER")  

headers = {
    "User-Agent": "Codex (OpenAI-Codex; +https://openai.com/codex) Python/3.12",
    "X-Client-Type": "codex"     
}

model = init_chat_model(
    model=model_name,
    model_provider=model_provider,
    api_key=api_key,
    base_url=base_url,
    default_headers=headers
)

agent = create_agent(
    model=model,
    tools=[remember_preference],
    system_prompt="你是一个贴心的助手，会记住用户的偏好设置。当用户表达偏好时，使用 remember_preference 工具记录下来。"
)


# ============ 测试案例 ============

print("\n" + "="*60)
print("案例1: 第一次记录偏好")
print("="*60)

result = agent.invoke({
    "messages": [HumanMessage(content="我喜欢喝咖啡，请记住这个偏好")]
})
print(f"用户: 我喜欢喝咖啡，请记住这个偏好")
print(f"助手: {result['messages'][-1].content}")

# 查看工具调用详情（学习重点）
print("\n--- 工具调用详情 ---")
for msg in result["messages"]:
    if msg.type == "tool":
        print(f"工具名称: {msg.name}")
        print(f"工具返回: {msg.content}")


print("\n" + "="*60)
print("案例2: 再次记录不同偏好")
print("="*60)

result = agent.invoke({
    "messages": [HumanMessage(content="我也喜欢看书，请记住")]
})
print(f"用户: 我也喜欢看书，请记住")
print(f"助手: {result['messages'][-1].content}")

print("\n--- 工具调用详情 ---")
for msg in result["messages"]:
    if msg.type == "tool":
        print(f"工具名称: {msg.name}")

print("\n" + "="*60)
print("案例3: 记录偏好并查看状态变化")

# 连续对话，观察状态变化
conversations = [
    "我喜欢用Python编程",

    "我偏好使用VS Code编辑器"
```

# InjectedStore

## store

Store 是跨会话持久化存储。

适合保存用户偏好、学习进度、用户档案、配置等长期信息。


**数据结构**

```text
namespace + key -> value
```


**使用**

```python
store.put(("users", "user_001"), "profile", {"data": profile})
item = store.get(("users", "user_001"), "profile")
```


**说明**

- `("users", "user_001")` 是命名空间。
- `"profile"` 是 key。
- `{"data": profile}` 是 value。
- 命名空间适合按业务、用户、租户隔离数据。



## InjectedState vs InjectedStore

`InjectedState` 解决“当前对话里有什么”的问题。

`InjectedStore` 解决“跨会话长期保存什么”的问题。


**对比**

| 维度     | InjectedState                  | InjectedStore                |
| :------- | :----------------------------- | :--------------------------- |
| 作用域   | 当前对话，单次 Agent 运行      | 跨会话，多次 Agent 运行共享  |
| 生命周期 | 对话结束即消失                 | 持久化存储                   |
| 典型用途 | 读取消息历史、当前对话中间结果 | 用户偏好、学习进度、配置信息 |
| 传入方式 | `InjectedState` 自动注入       | `InjectedStore()` 自动注入   |
| 数据组织 | 扁平字典                       | 命名空间 + key               |







## 工具中读写 Store

`InjectedStore()` 让工具可以直接读写 Store。

适合保存用户档案、课程进度、偏好设置等长期数据。


**使用**

```python
from typing import Annotated

from langgraph.store.base import BaseStore
from langgraph.store.memory import InMemoryStore
from langchain.tools import InjectedStore, tool


# 创建一个内存 Store。
# 实际项目中可以替换为数据库、Redis 或其他持久化存储。
store = InMemoryStore()


# 预置用户档案
store.put(("users", "user_001"), "profile", {
    "data": {
        "name": "小明",
        "level": "入门",
        "completed_courses": ["HTML 基础教程"],
    }
})


@tool
def get_user_profile(
    store: Annotated[BaseStore, InjectedStore()],
) -> str:
    """获取当前用户的学习档案信息。"""
    item = store.get(("users", "user_001"), "profile")

    if item is None:
        return "未找到用户档案"

    profile = item.value["data"]

    return (
        f"用户档案：姓名={profile['name']}，"
        f"水平={profile['level']}，"
        f"已完成课程={', '.join(profile['completed_courses'])}"
    )


@tool
def save_course_progress(
    course_name: str,
    store: Annotated[BaseStore, InjectedStore()],
) -> str:
    """保存用户学习进度。"""
    item = store.get(("users", "user_001"), "profile")

    if item:
        profile = item.value["data"]
    else:
        profile = {
            "name": "小明",
            "level": "入门",
            "completed_courses": [],
        }

    if course_name not in profile["completed_courses"]:
        profile["completed_courses"].append(course_name)

    store.put(("users", "user_001"), "profile", {"data": profile})

    return (
        f"学习进度已更新！已完成 {len(profile['completed_courses'])} 门课程："
        f"{', '.join(profile['completed_courses'])}"
    )
    
print(get_user_profile.invoke({}))
print(save_course_progress.invoke({"course_name": "Python3 基础教程"}))
print(get_user_profile.invoke({}))
```


**运行结果**

```text
用户档案：姓名=小明，水平=入门，已完成课程=HTML 基础教程
学习进度已更新！已完成 2 门课程：HTML 基础教程, Python3 基础教程
用户档案：姓名=小明，水平=入门，已完成课程=HTML 基础教程, Python3 基础教程
```


**注意**

- `InjectedStore()` 是框架注入参数，不应该让用户或模型手动填写。
- 自动注入通常发生在 Agent / ToolNode 运行工具时。
- 手动直接测试工具时，不同 LangChain 版本行为可能不同，推荐通过 Agent 传入 `store` 验证。



## Agent 中使用 Store

把 `store` 传给 `create_agent()` 后，Agent 中的工具就能通过 `InjectedStore()` 访问它。


**完整案例**

```python
from typing import Annotated

from langgraph.store.base import BaseStore
from langgraph.store.memory import InMemoryStore
from langchain.tools import InjectedStore, tool
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage


# 创建 Store 并预置课程数据
store = InMemoryStore()
store.put(("runoob", "courses"), "catalog", {
    "data": {
        "Python3 基础教程": {"price": "免费", "duration": "20小时"},
        "Python 数据分析": {"price": "会员", "duration": "30小时"},
        "HTML 基础教程": {"price": "免费", "duration": "15小时"},
    }
})


@tool
def query_course_price(
    course_name: str,
    store: Annotated[BaseStore, InjectedStore()],
) -> str:
    """查询菜鸟教程 RUNOOB 中指定课程的价格信息。

    Args:
        course_name: 课程名称
    """
    item = store.get(("runoob", "courses"), "catalog")
    catalog = item.value["data"] if item else {}

    if course_name in catalog:
        info = catalog[course_name]
        return (
            f"《{course_name}》- "
            f"价格：{info['price']}，"
            f"学习时长：{info['duration']}"
        )

    return f"未找到课程《{course_name}》"


model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)

agent = create_agent(
    model=model,
    tools=[query_course_price],
    store=store,
    system_prompt="你是菜鸟教程 RUNOOB 的课程顾问。",
)


result = agent.invoke({
    "messages": [
        HumanMessage(content="Python3 基础教程和 Python 数据分析分别多少钱？")
    ]
})

print(result["messages"][-1].content)
```


**运行结果**

```text
根据查询结果：
- 《Python3 基础教程》是免费的，学习时长约 20 小时
- 《Python 数据分析》是会员课程，学习时长约 30 小时

建议先从免费的 Python3 基础教程开始学习。
```


**适合场景**

- 保存用户偏好
- 保存学习进度
- 保存用户档案
- 保存长期配置
- 多轮会话共享同一份业务数据


**结论**

`InjectedState` 读当前对话，`InjectedStore()` 读写长期存储。

如果数据只在当前对话中使用，用 `InjectedState`。

如果数据需要跨会话保留，用 `InjectedStore()`。





# InjectedToolArg

`InjectedToolArg` 是通用注入标记。

它表示这个参数不是由模型提供，而是由框架在工具运行时注入。


**使用**

```python
from typing import Annotated

from langchain.tools import InjectedToolArg, tool


@tool
def my_tool(
    normal_param: str,
    injected_param: Annotated[str, InjectedToolArg],
) -> str:
    """包含注入参数的工具。"""
    return f"normal={normal_param}, injected={injected_param}"
```


**说明**

- `InjectedToolArg` 是通用注入标记。
- `InjectedState`、`InjectedStore`、`InjectedToolCallId` 都属于更具体的注入标记。
- 大多数场景优先使用专用注入标记。
- 自定义注入逻辑时，再考虑直接使用 `InjectedToolArg`。





# 短期记忆

## Checkpointer

Checkpointer 用来保存线程级状态，让多轮对话延续上下文。


**使用**

```python
from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()

agent = create_agent(
    model=model,
    tools=[],
    checkpointer=checkpointer,
)
```


## thread_id

`thread_id` 用来区分不同会话线程。


**使用**

```python
config = {"configurable": {"thread_id": "user-001"}}

agent.invoke(
    {"messages": [{"role": "user", "content": "我叫小明"}]},
    config=config,
)

agent.invoke(
    {"messages": [{"role": "user", "content": "我叫什么？"}]},
    config=config,
)
```


## 常见记忆策略

- 截断消息
- 删除消息
- 总结消息
- 自定义记忆策略


**理解**

- Checkpointer 保存的是当前会话线程状态。
- 上下文太长时不能无脑全塞。
- 要在保留关键上下文和控制 token 成本之间平衡。





# 人工介入

## interrupt()

人工干预是在关键节点中断执行，等待人工审批、编辑或补充。


**使用**

```python
from langgraph.types import interrupt


@tool
def approve_refund(order_id: str) -> str:
    decision = interrupt({"order_id": order_id, "action": "approve_refund"})
    return f"审批结果：{decision}"
```


## 决策类型

- approve
- reject
- edit
- respond


## 适合场景

- 支付
- 退款
- 删除数据
- 发邮件
- 修改生产配置



# 多 Agent

## 为什么使用多 Agent

多 Agent 适合把复杂任务拆给多个专门角色处理，降低单 Agent 负担。


## 常见模式

### 子代理

把专门能力封装成子代理，主代理像调用工具一样调用。


**适合**

- 研究员 Agent
- SQL Agent
- 检索 Agent
- 审核 Agent


### Handoffs

交接模式适合“主导权切换”，由一个 Agent 把会话接力给另一个 Agent。


**适合**

- 客服分流
- 售前转售后
- 普通支持转专家支持


### Skills

技能模式适合按需加载一组固定能力，而不是把所有能力都塞进主 Agent。


### Router

路由模式用于把请求分发到不同知识域、不同数据源或不同专家 Agent。


### Custom Workflow

自定义工作流适合强控制流程，例如固定顺序执行检索、分析、汇总。


## 选择建议

| 模式 | 适合场景 |
| :-- | :-- |
| 子代理 | 主 Agent 调多个专家工具 |
| Handoffs | 会话控制权切换 |
| Skills | 能力按需挂载 |
| Router | 多领域分流 |
| Custom Workflow | 固定业务流程 |


**建议**

- 先把单 Agent 做清楚，再考虑多 Agent。
- 职责边界要清晰。
- 多 Agent 一定要配状态管理和 tracing。
