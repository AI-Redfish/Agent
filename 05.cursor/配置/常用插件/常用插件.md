# Remote SSH

**安装**

插件市场搜索并安装：Remote - SSH



**配置SSH主机**

1，按 Ctrl+Shift+P 打开命令面板

2、在命令面板中执行 Remote-SSH: Open SSH Configuration File

3、按enter打开config主机配置文件

```
Host 自定义主机名1
    HostName 服务器ip
    User 账号
    Port 22
    PubkeyAuthentication no
    PreferredAuthentications password
    # password 密码登陆不支持将密码配置到该配置文件，可以写在注释中，每次查看。
    # java服务路径 ：/java/home
    
    
Host 自定义主机名2
    HostName 服务器ip
    User 账号
    Port 22
    PubkeyAuthentication no
    PreferredAuthentications password
    # password 密码登陆不支持将密码配置到该配置文件，可以写在注释中，每次查看。
    # java服务路径 ：/java/home
```



**连接服务器**

1、按 Ctrl+Shift+P 打开命令面板

2、在命令面板中执行 Remote-SSH:Connect to Host

3、按enter后会弹出配置好的主机别名列表

4、从列表中选择需要连接的主机

5、选择主机后cursor会打开一个新的窗口

6，然后会提示输入密码（如果使用密码登录）

7、连接成功后，新窗口左下角会显示连接的主机别名

8、“打开文件夹”打开服务器任意文件夹进行编辑操作。

9、在cursor的shell窗口中，执行服务器命令。



通过remote-ssh连接到linux服务器后，可以通过chat等AI方式操作服务器。
