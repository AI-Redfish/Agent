#  AGENTS.md

为了让 AI 更好地理解你的项目，建议创建 AGENTS.md 文件。

把下面的内容保存为 Markdown 文件，文件路径为 **项目根目录/AGENTS.md**：

```
# 项目指令

- 代码修改后运行 `npm run check`
- 不要直接在本地执行生产环境迁移
- 回复保持简洁，不要过多解释
- 使用 TypeScript 严格模式编写代码
- 遵循项目现有的代码风格
```



Pi Agent 会在启动时自动加载这个文件。

同时也会加载来自 **~/.pi/agent/AGENTS.md** 的全局指令和父目录中的指令文件。

更新 AGENTS.md 后，使用 **/reload** 命令即可热重载，无需重启。
