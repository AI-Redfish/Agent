# 安装

```
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```



# 卸载

**卸载插件**

```
# 查看已经安装的插件。
pnpm dsh plugin --profile web list

# 卸载插件
pnpm dsh plugin --profile web remove <插件包名>
```

**卸载dsh**

1，停止dsh服务

2，删除dsh源码目录。

3，删除配置数据：rm -rf ~/.dsh
