# 概述

**Profile 是 DSH 的"配置隔离单元"**，它的设计让同一个 DSH 安装可以服务于多个完全不同的使用场景，而不会互相干扰。



实现配置隔离，根据需要启动指定配置的DSH服务：插件，工具，密钥，模型。



DSH支持多服务实例同时启动(使用不通的profile)：

```
# 终端 A：启动 Web UI
dsh start --profile web

# 终端 B：运行自动化任务
dsh headless --profile headless "分析代码库"

# 终端 C：启动代码审查服务
dsh start --profile code-review --port 8081
```
