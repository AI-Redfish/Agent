# 概述

| `cordis.yml` | `cordis.patch.yml`                                 |                                              |
| :----------- | :------------------------------------------------- | -------------------------------------------- |
| **性质**     | **自动生成的合成文件**                             | **用户自定义的补丁文件**                     |
| **操作权限** | **❌ 禁止手动编辑**                                 | **✅ 用户唯一手动编辑区**                     |
| **内容来源** | 由系统根据 `package.json` 中定义的 Bundle 自动合成 | 用户手动写入的配置条目                       |
| **作用**     | 反映出当前 Profile 的**完整、基础**配置            | 在 `cordis.yml` 之上进行**覆盖、新增或调整** |
