# /loop

```
/loop [时间间隔] [任务指令]
支持 s (秒), m (分), h (时), d (天)。
如果不写时间，默认是每 10分钟 执行一次。
```



**错过即跳过**

当一个循环任务到达执行周期时，如果 Claude 正在忙碌（上一个任务尚未执行完毕），此次执行机会会被跳过（Skipped）。



**案例**

```
监控部署状态
（每5分钟检查一次）：
/loop 5m 检查当前项目的部署状态，如果有异常分析日志


自动巡检 PR
（每30分钟检查一次 CI 失败）：
/loop 30m 检查当前分支的 PR，如果 CI 失败就尝试修复


生成每日摘要
（每24小时总结一次）
/loop 24h 总结过去24小时 main 分支的提交记录


嵌套命令
（每20分钟执行一次其他命令）
/loop 20m /review-pr 1234
```<websource>source_group_web_7</websource>
```





**相关命令**

| 操作         | 命令/方法             | 说明                                 |
| :----------- | :-------------------- | :----------------------------------- |
| **查看任务** | `CronList`            | 列出当前会话所有定时任务的 ID 和计划 |
| **停止任务** | `/loop-stop [任务ID]` | 根据 ID 停止特定任务                 |
| **删除任务** | `CronDelete(任务ID)`  | 通过内置工具删除任务                 |



# /goal

设定一个可验证的目标，Claude Code 会自主多轮迭代，直到目标达成才停止，全程无需逐轮人工干预。

```
/goal <目标完成条件>

/goal [做某工作] until [可衡量的结束状态] without [必须遵守的约束]
```
