# 官方地址

https://github.com/anthropics/knowledge-work-plugins



# 定位

简单来说，它的作用是**把通用型的 Claude，变成某个特定岗位的“专家助手”**。

**目前已开源的 11 个插件**

Anthropic 开源了 11 个插件，覆盖了多个常见职能岗位：

| 插件                         | 作用                                                         | 支持的连接器                                                 |
| :--------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **productivity**             | 管理任务、日历、日常工作流和个人上下文                       | Slack, Notion, Asana, Linear, Jira, Monday, ClickUp, Microsoft 365 |
| **sales**                    | 研究潜在客户、准备电话会议、审查销售管道、起草外联邮件、构建竞争对战卡 | Slack, HubSpot, Close, Clay, ZoomInfo, Notion, Jira, Fireflies, Microsoft 365 |
| **customer-support**         | 分类工单、起草回复、打包升级问题、研究客户上下文、将已解决问题转化为知识库文章 | Slack, Intercom, HubSpot, Guru, Jira, Notion, Microsoft 365  |
| **product-management**       | 撰写产品规格、规划路线图、综合用户研究、同步利益相关者、追踪竞争态势 | Slack, Linear, Asana, Monday, ClickUp, Jira, Notion, Figma, Amplitude, Pendo, Intercom, Fireflies |
| **marketing**                | 起草内容、规划营销活动、执行品牌调性、竞品简报、跨渠道绩效报告 | Slack, Canva, Figma, HubSpot, Amplitude, Notion, Ahrefs, SimilarWeb, Klaviyo |
| **legal**                    | 审阅合同、分类NDA、合规导航、风险评估、会议准备、起草模板回复 | Slack, Box, Egnyte, Jira, Microsoft 365                      |
| **finance**                  | 准备日记账分录、对账、生成财务报表、分析差异、管理结账、支持审计 | Snowflake, Databricks, BigQuery, Slack, Microsoft 365        |
| **data**                     | 查询、可视化和解读数据集——编写SQL、运行统计分析、构建仪表板、验证工作成果 | Snowflake, Databricks, BigQuery, Definite, Hex, Amplitude, Jira |
| **enterprise-search**        | 跨邮件、聊天、文档和Wiki进行统一搜索——一次查询覆盖公司所有工具 | Slack, Notion, Guru, Jira, Asana, Microsoft 365              |
| **bio-research**             | 连接临床前研究工具和数据库（文献检索、基因组学分析、靶点优先级排序），加速早期生命科学研发 | PubMed, BioRender, bioRxiv, [ClinicalTrials.gov](https://clinicaltrials.gov/), ChEMBL, Synapse, Wiley, Owkin, Open Targets, Benchling |
| **cowork-plugin-management** | 为组织的特定工具和工作流创建新插件或定制现有插件             | —                                                            |
