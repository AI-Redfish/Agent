# Agents

## Auto-Run

### **Auto-Run mode**

**Ask Every Time**

每次执行命令/改文件都弹窗确认。最安全、最慢。



**Use Allowlist**

在白名单内的操作自动执行，超出白名单才询问。

这是最推荐的日常档（效率和安全平衡）。



**Run Everything**

基本全部自动执行，不再频繁确认。最快，但风险最高（可能一口气执行很多你没细看的操作）。





如果你是日常开发，建议：

- 默认用 Use Allowlist

- 只在你非常确定任务范围时，临时切到 Run Everything

- 关键仓库/生产相关代码回到 Ask Every Time

如果你愿意，我可以下一步帮你把 Allowlist 规则按你常用栈（java/springboot/vue3）给一版推荐清单。



# 常用操作

## 重置设置

**完全关闭 Cursor**

确保 Cursor 应用程序已从任务栏/程序坞完全退出，包括后台进程。

 

**删除 Cursor 的用户数据文件夹**

根据你的操作系统，找到并删除对应的文件夹：



Windows

1. 按 `Win + R` 打开“运行”。
2. 输入 `%APPDATA%\Cursor` 并回车。
3. 删除打开的 `Cursor` 文件夹。



macOS

1. 打开“访达”(Finder)。
2. 按 `Command + Shift + G`。
3. 输入 `~/Library/Application Support/Cursor` 并前往。
4. 删除 `Cursor` 文件夹。



Linux

1. 打开文件管理器或终端。
2. 导航到 `~/.config/` 目录。
3. 删除 `Cursor` 文件夹。



**(可选但推荐) 清理缓存**

为了更彻底地重置，可以一并删除缓存文件：

Windows: 删除 `%LOCALAPPDATA%\Cursor\Cache`

macOS: 删除 `~/Library/Caches/Cursor`

Linux: 删除 `~/.cache/Cursor`

 



**重新启动 Cursor**

再次打开 Cursor。它会像第一次安装一样，创建全新的配置文件夹，所有设置都恢复为默认状态。
