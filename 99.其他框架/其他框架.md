# BetterHarness

Better Harness 是一个为AI编程助手（AI编程Agent）设计的开源工作流审查与优化框架**。**

它由QoderAI团队开发，旨在解决AI编程中“代码能跑，但不代表做对了”的核心痛点。





# HarnessHandbook

Harness Handbook旨在解决AI智能体“**行为定位**”难题。简单来说，就是当你想修改AI的某个行为时，它的代码可能分散在成百上千个文件中，很难找到所有相关的地方。Harness Handbook就像一张“行为地图”，自动将代码按“**系统在运行时做了什么**”来组织，而不是按传统的“文件-函数”来排列。
