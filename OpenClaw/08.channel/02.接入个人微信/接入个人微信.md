# **安装**

https://www.npmjs.com/package/@tencent-weixin/openclaw-weixin-cli

具体操作步骤打开微信查看OpenClaw微信插件即可。



在安装OpenClaw的宿主机上执行如下命令即可：

```
npx -y @tencent-weixin/openclaw-weixin-cli install
```

安装后完成后，执行如下命令：

```
openclaw gateway stop
openclaw gateway start
```

个人微信扫码控制台输出的二维码即可实现通讯。





# **卸载**

```
openclaw plugins uninstall @tencent-weixin/openclaw-weixin
npm uninstall -g @tencent-weixin/openclaw-weixin-cli
```
