# 环境

**前提**

Node.js：推荐 `24`，最低 `22.14+`

# 安装

**安装命令**

```bash
npm i -g openclaw
# 如果速度慢可以指定国内镜像
npm i -g openclaw --registry=https://registry.npmmirror.com
```



**初始化命令**

```bash
# 运行交互式初始化/配置向导，用来配置模型、通道、Gateway、工作区等。
# --install-daemon:让 OpenClaw Gateway 作为系统后台服务常驻运行、通常可开机自启。
openclaw onboard
# openclaw onboard --install-daemon
```





**入口命令**

```bash
# 启动网关，接受所有来源的openClaw命令。可以不指定port，默认18789
# 等价理解：启动 OpenClaw 的“服务端”。
openclaw gateway --port 18789

# 打开 OpenClaw 的网页控制台
openclaw dashboard

# 打开终端版聊天界面 ，默认连本地正在运行的 Gateway。
openclaw tui

# 打开终端 TUI，但不连本地，而是连接远程 Gateway。
openclaw tui --url ws://<host>:<port> --token <gateway-token>

# 如果 Gateway 使用密码鉴权
openclaw tui --url ws://<host>:<port> --password <password>
```



# 卸载

```
openclaw uninstall --all --yes --non-interactive
npx -y openclaw uninstall --all --yes --non-interactive
```





# 工作原理

OpenClaw 不是一个普通的聊天机器人，而是一个住在你电脑里的私人秘书，它能通过微信、WhatsApp、Telegram 等聊天软件接收指

令，帮你发邮件、查日历、打开浏览器、运行命令，甚至 24 小时自动做事！

## gateway

**认证**

确保只有你授权的平台（如微信）才能连接。



**路由**

一个openClaw可以有多个工作空间。

gateway把消息送到正确的工作空间(workspace)。



**日志记录（Logging）**

记录所有交互，方便调试和审计
