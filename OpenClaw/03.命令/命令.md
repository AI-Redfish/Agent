



# gateway命令

```
# 查看 Gateway 状态
openclaw gateway status

# 在前台运行（适合调试）
openclaw gateway --port 18789

# 详细日志模式
openclaw gateway --port 18789 --verbose

# 强制占用端口并启动（解决端口冲突）
openclaw gateway --force

# 重启 Gateway
openclaw gateway restart

# 停止 Gateway
openclaw gateway stop

# 查看实时日志
openclaw logs --follow
```



# model命令

```
# 添加备用模型
openclaw models add

# 查看已配置的模型
openclaw models list

# 设置默认模型
openclaw models set-default <model-name>
```



# Agent命令

```
# to指定消息送到谁
openclaw message send --to +1234567890 --message "Hello from OpenClaw"

# 用指定 agent 发一轮对话。
# 该命令连接到该 agent 的 direct 默认会话，不是每次都新建一个全新的 session。
openclaw agent --agent ops --message "你好啊" --thinking high

# 用指定 session 发消息：
openclaw agent --session-id 1234 --message "你好啊" --thinking high

# 列出所有 Agent
openclaw agents list

# 添加新 Agent
openclaw agents add <agent-name>

# 编辑 Agent 配置
openclaw agents edit <agent-name>

# 编辑 Agent 的 SOUL
openclaw agents edit <agent-name> --soul

# 删除agent
openclaw agents remove <agent-name>
```



# Sessions命令

```
# 查看所有会话的session信息。
# 如果没有使用--all-agents，则默认仅查询main默认agent的session
openclaw sessions --all-agents
```



# Skill命令

```
# 列出已安装的技能
openclaw skills list

# 搜索技能（需要先安装 clawhub）
clawhub search <关键词>

# 安装技能
clawhub install <skill-name>

# 卸载技能
openclaw skills uninstall <skill-name>
```



# Channel命令

```
# 列出所有渠道
openclaw channels list

# 添加新渠道
openclaw channels add

# 删除渠道
openclaw channels remove <channel-name>

# 重启渠道
openclaw channels restart <channel-name>
```



# Plugin命令

```
# 列出所有插件
openclaw plugins list

# 启用插件
openclaw plugins enable <plugin-name>

# 禁用插件
openclaw plugins disable <plugin-name>
```



# 更新命令

```
# 更新到最新稳定版
openclaw update

# 切换版本通道
openclaw update --channel stable   # 稳定版
openclaw update --channel beta     # 测试版
openclaw update --channel dev      # 开发版
```





# 日志

```
# 查看实时日志
openclaw logs --follow

# 查看特定 Agent 的日志
openclaw logs --agent main

# 查看错误日志
openclaw logs --level error
```



# 健康检查

```
# 全面健康检查并尝试修复配置问题
openclaw doctor

# 快速健康检查
openclaw health

# 查看 Gateway 和渠道整体状态
openclaw status


```
