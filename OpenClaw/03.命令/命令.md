



# gateway命令

```
# 查看 Gateway 状态
openclaw gateway status

# 在前台运行（适合调试）
openclaw gateway --port 18789

# 详细日志模式
openclaw gateway --port 18789 --verbose

# 强制占用端口并启动（解决端口冲突）
openclaw gateway --force

# 重启 Gateway
openclaw gateway restart

# 停止 Gateway
openclaw gateway stop

# 查看实时日志
openclaw logs --follow
```
