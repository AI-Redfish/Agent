# 安装

保证本地有node,版本>22。



管理员身份执行powershell

```
npm install -g openclaw@latest
```



安装完成后进行配置，引导你完成环境、API Key 等设置。

```
openclaw onboard
```

根据提示一路配置即可，可以不配置的都可以先不配置。

其中hooks可以都勾选安装。



安装结束后默认会自动打开浏览器访问。

如果cmd黑窗口关闭，则服务关闭。



# 常用命令

**启动网关（常用）**

配置完成后，启动网关服务：

```
openclaw gateway --port 18789
# 或 opeanclaw gateway run
```

18789 为默认端口，可按需改成其他端口。



**打开带token的Web**

```
openclaw dashboard
```

以上命令会自动在浏览器里打开对应地址即可聊天。



**作为后台服务运行**

希望关闭终端后仍保持运行：

```
openclaw onboard --install-daemon
```

会安装/配置守护进程，让 OpenClaw 在后台持续运行。



**检查环境是否正常**

```
openclaw doctor
```

输出里相关项都显示 ✅ 表示配置正常。
