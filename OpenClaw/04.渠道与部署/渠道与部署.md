# 渠道

## 接入链路

```text
平台消息 -> Channel / Plugin -> Gateway -> Workspace / LLM / Skills -> 平台回复
```

## 通用命令

```bash
openclaw gateway status
openclaw dashboard
openclaw channels status
openclaw plugins list
openclaw logs --follow
openclaw doctor
```

## 微信

```bash
npx -y @tencent-weixin/openclaw-weixin-cli@latest install
openclaw plugins install "@tencent-weixin/openclaw-weixin"
openclaw config set plugins.entries.openclaw-weixin.enabled true
openclaw channels login --channel openclaw-weixin
openclaw gateway restart
```

- 流程：安装插件 → 二维码授权 → Dashboard 确认启用 → 测试消息

## 飞书

```bash
openclaw plugins enable feishu
openclaw channels add
```

- 必填：`App ID`、`App Secret`、机器人能力、权限配置、事件订阅、应用发布
- 事件：`im.message.receive_v1`、`im.message.message_read_v1`、`im.chat.member.bot.added_v1`、`im.chat.member.bot.deleted_v1`

# 部署

## 适用场景

- `7x24` 在线
- 远程访问
- 长期接入渠道
- 不依赖本机开机

## 上线前确认

1. 模型供应商 / 计费方式
2. 端口 / 防火墙 / 安全组
3. Gateway 鉴权模式
4. Dashboard / API 地址
5. 搜索能力
6. 外部渠道

## 阿里云

- 放通端口
- 配模型 API Key
- 确认 Dashboard / Token
- API 调用场景确认 HTTP / Responses 能力
- `Coding Plan` 的 Key / Base URL 不能和普通按量计费混用

## 顺序

1. 先本地跑通
2. 再上云
3. 云上先验证 Gateway
4. 再接 Dashboard
5. 再接渠道 / 搜索

## 运维

```bash
openclaw gateway status
openclaw gateway restart
openclaw logs --follow
openclaw doctor
```

- Docker：`https://docs.openclaw.ai/install/docker`
- 搜索限制：中国内地地域（不含香港）联网搜索有限制；香港 / 海外看 `brave-search` 文档

# 安全

## 原则

- 平台权限最小化
- 先用测试群 / 测试号
- 不泄露二维码、App Secret、Token
