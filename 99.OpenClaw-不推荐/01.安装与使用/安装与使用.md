# 环境

**前提**

Node.js：推荐 `24`，最低 `22.14+`

# 安装

**安装命令**

```bash
# npm i -g openclaw
# 如果速度慢可以指定国内镜像
npm install -g openclaw@latest --registry=https://registry.npmmirror.com
```



**初始化命令**

```bash
# 运行交互式初始化/配置向导，用来配置模型、通道、Gateway、工作区等。
# --install-daemon:让 OpenClaw Gateway 作为系统后台服务常驻运行、通常可开机自启。
openclaw onboard
# openclaw onboard --install-daemon

#  Model/auth provider
#  如果选择OpenAI等provider，会跳转到官网进行鉴权。不适用于模型中转平台。
# 因此，为保证配置通用性，不建议通过命令行配置model provider。

# 后续选项均默认或者跳过
```

**入口命令**

```bash
# 启动网关，接受所有来源的openClaw命令。可以不指定port，默认18789
# 等价理解：启动 OpenClaw 的“服务端”。
# openclaw gateway --port 18789
openclaw gateway

# 打开 OpenClaw 的网页控制台
openclaw dashboard

# 打开终端版聊天界面 ，默认连本地正在运行的 Gateway。
openclaw tui

# 打开终端 TUI，但不连本地，而是连接远程 Gateway。
openclaw tui --url ws://<host>:<port> --token <gateway-token>

# 如果 Gateway 使用密码鉴权
openclaw tui --url ws://<host>:<port> --password <password>
```



**停止服务**

```
# 停止所有服务
openclaw stop
```









# 卸载

```
openclaw uninstall --all --yes --non-interactive
npx -y openclaw uninstall --all --yes --non-interactive
```

**检查是否卸载成功**

```
# 检查命令是否存在
openclaw --version
# 应该显示 "command not found"
```



**检查配置文件是否已删除**

```
# Linux/macOS
ls -la ~/.openclaw
ls -la ~/.config/openclaw
ls -la ~/.local/share/openclaw

# Windows
dir %USERPROFILE%\.openclaw
dir %APPDATA%\openclaw
dir %LOCALAPPDATA%\openclaw
```



# 工作原理

OpenClaw 不是一个普通的聊天机器人，而是一个住在你电脑里的私人秘书，它能通过微信、WhatsApp、Telegram 等聊天软件接收指

令，帮你发邮件、查日历、打开浏览器、运行命令，甚至 24 小时自动做事！

![img](安装与使用Resource\1_eZX31-3n0KTJ2MY1RB0JBg.png)





## gateway

**认证**

确保只有你授权的平台（如微信）才能连接。



**路由**

一个openClaw可以有多个工作空间。

gateway把消息送到正确的工作空间(workspace)。



**日志记录（Logging）**

记录所有交互，方便调试和审计



## Agent

每个 Agent 都有独立的 Workspace（工作区）。







# 接入个人微信

**安装**

https://www.npmjs.com/package/@tencent-weixin/openclaw-weixin-cli

具体操作步骤打开微信查看OpenClaw微信插件即可。



在安装OpenClaw的宿主机上执行如下命令即可：

```
npx -y @tencent-weixin/openclaw-weixin-cli install
```

安装后完成后，执行如下命令：

```
openclaw gateway stop
openclaw gateway start
```

个人微信扫码控制台输出的二维码即可实现通讯。



**卸载**

```
openclaw plugins uninstall @tencent-weixin/openclaw-weixin
npm uninstall -g @tencent-weixin/openclaw-weixin-cli
```
