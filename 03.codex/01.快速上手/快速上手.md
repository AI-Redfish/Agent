# Codex 快速上手

## 安装

- CLI：`npm install -g @openai/codex`
- 卸载：`npm uninstall -g @openai/codex`
- IDE 插件：`openai.chatgpt`
- 官方文档：`https://developers.openai.com/codex`

## 登录

- 运行：`codex`
- 按提示选择 `Sign in with ChatGPT` 或 API Key

## 使用

- 当前目录启动：`codex`
- 指定目录启动：`codex -C D:\develop\GitNote`
- 桌面 App：`codex app`
- VS Code 发送选中代码到对话：
- `Ctrl+Shift+P`
- 执行 `chatgpt.addToThread`
