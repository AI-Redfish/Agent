# 会话记忆

## Checkpointer

Checkpointer 用于保存 Agent 的会话状态，让多轮对话延续上下文。



**使用**

```
from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()

agent = create_agent(
    model=model,
    tools=[],
    checkpointer=checkpointer
)
```



## thread_id

`thread_id` 用来区分不同会话。



**使用**

```
config = {'configurable': {'thread_id': 'user-001'}}

agent.invoke({'messages': [{'role': 'user', 'content': '我叫小明'}]}, config=config)
agent.invoke({'messages': [{'role': 'user', 'content': '我叫什么？'}]}, config=config)
```



**使用场景**

- 多轮对话
- 用户会话隔离
- 恢复历史上下文



# 跨会话存储

## Store

Store 用于保存跨会话数据，例如用户偏好、长期记忆、业务配置。



**使用**

```
store.put(('preferences',), 'language', '中文')
item = store.get(('preferences',), 'language')
```



## Checkpointer vs Store

二者都和记忆相关，但生命周期不同。



**区别**

| 能力 | 用途 | 生命周期 |
| :-- | :-- | :-- |
| Checkpointer | 保存会话线程状态 | 按 `thread_id` 管理 |
| Store | 保存跨会话长期数据 | 按命名空间和 key 管理 |



# 人工介入

## interrupt()

人工介入用于在 Agent 执行到关键步骤时暂停，等待人工审批、补充信息或确认。



**使用**

```
from langgraph.types import interrupt

@tool
def approve_refund(order_id: str) -> str:
    decision = interrupt({'order_id': order_id, 'action': 'approve_refund'})
    return f'审批结果：{decision}'
```



**使用场景**

- 退款审批
- 删除数据
- 发邮件或发消息
- 下单、支付、转账
- 修改生产系统配置



# 多 Agent

## 子 Agent 作为工具

多 Agent 适合把复杂任务拆成多个角色，例如研究员、规划员、执行员、审核员。



**使用**

```
@tool
def research_task(query: str) -> str:
    """调用研究 Agent 完成资料检索。"""
    result = research_agent.invoke({'messages': [{'role': 'user', 'content': query}]})
    return result['messages'][-1].content
```



**建议**

- 会话上下文用 Checkpointer。
- 用户长期偏好用 Store。
- 高风险工具必须支持人工确认。
- 多 Agent 要先明确职责边界，不要为了拆分而拆分。
