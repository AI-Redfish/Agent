# 消息类型

## Messages

Messages 用来描述一次对话中的不同角色消息。



**类型说明**

| 类型 | 说明 |
| :-- | :-- |
| `SystemMessage` | 系统提示词，定义角色和规则 |
| `HumanMessage` | 用户输入 |
| `AIMessage` | AI 回复，可包含工具调用信息 |
| `ToolMessage` | 工具执行结果 |



**使用**

```
from langchain_core.messages import SystemMessage, HumanMessage

messages = [
    SystemMessage(content='你是一个严谨的 Python 教师。'),
    HumanMessage(content='什么是 LangChain？'),
]

response = model.invoke(messages)
```



## 字典消息

LangChain 也支持使用字典形式描述消息。



**使用**

```
messages = [
    {'role': 'system', 'content': '你是技术助手'},
    {'role': 'user', 'content': '解释 RAG'},
]
```



**建议**

- 简单示例可以用字典。
- 复杂逻辑或类型检查更适合使用消息类。



# 提示词

## System Prompt

`system_prompt` 用于约束 Agent 的角色、边界和输出格式。



**使用**

```
agent = create_agent(
    model=model,
    tools=[],
    system_prompt='你是一个资深 Python 教师，回答要包含示例。'
)
```



**写法建议**

- 明确角色：模型应该扮演谁。
- 明确任务：模型需要完成什么。
- 明确边界：哪些事情不能做。
- 明确输出：语言、格式、长度、结构。
- 明确工具规则：什么时候调用工具，什么时候直接回答。



## dynamic_prompt

动态提示词适合根据用户、环境或业务状态生成不同规则。



**使用**

```
from langchain.agents.middleware import dynamic_prompt

@dynamic_prompt
def user_prompt(request):
    level = request.runtime.context.get('level', 'normal')
    return f'当前用户等级：{level}，请根据等级调整解释深度。'
```



**使用场景**

- 不同用户等级使用不同解释深度。
- 不同租户使用不同业务规则。
- 根据运行环境动态切换提示词。



# 流式输出

## stream_mode="messages"

逐步输出模型消息内容，适合聊天界面。



**使用**

```
for token, metadata in agent.stream(input_data, stream_mode='messages'):
    print(token.content, end='')
```



## stream_mode="updates"

输出 Agent 每个节点的增量变化，适合调试。



**使用**

```
for update in agent.stream(input_data, stream_mode='updates'):
    print(update)
```



**建议**

- 稳定规则放到 `system_prompt`。
- 个性化规则用动态提示词。
- 长对话要裁剪、总结或使用 Checkpointer。
- UI 展示优先使用流式输出。
