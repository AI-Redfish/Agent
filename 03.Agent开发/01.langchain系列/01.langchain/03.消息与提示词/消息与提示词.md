# 消息基础

## 文本提示与消息提示

LangChain 同时支持：

- 直接传纯文本
- 传标准消息列表

简单问答可以直接传文本；涉及角色、工具、上下文时，更适合消息格式。


## 消息类型

| 类型 | 说明 |
| :-- | :-- |
| `SystemMessage` | 系统规则与边界 |
| `HumanMessage` | 用户输入 |
| `AIMessage` | 模型回复，可包含工具调用 |
| `ToolMessage` | 工具执行结果 |


**使用**

```python
from langchain_core.messages import SystemMessage, HumanMessage

messages = [
    SystemMessage(content="你是一个严谨的 Python 教师。"),
    HumanMessage(content="什么是 LangChain？"),
]

response = model.invoke(messages)
```


## 字典消息

LangChain 也支持字典格式消息。


**使用**

```python
messages = [
    {"role": "system", "content": "你是技术助手"},
    {"role": "user", "content": "解释 RAG"},
]
```


**建议**

- 简单示例可用字典
- 复杂逻辑优先消息类


# 消息内容

## 内容块

消息页强调，消息内容不只是纯文本，还可以由标准内容块组成。

常见价值：

- 支持多模态
- 支持结构化片段
- 支持推理块、工具调用块


## 多模态消息

当模型支持时，消息中可以混合文本、图片等内容块，而不是只传一段字符串。


# 提示词

## System Prompt

`system_prompt` 用于定义 Agent 的角色、目标和边界。


**使用**

```python
agent = create_agent(
    model=model,
    tools=[],
    system_prompt="你是一个资深 Python 教师，回答要包含示例。"
)
```


**写法建议**

- 角色要明确
- 任务要明确
- 边界要明确
- 输出格式要明确
- 工具调用规则要明确


## 动态提示词

动态提示词适合根据用户、权限或环境实时生成规则。


**使用**

```python
from langchain.agents.middleware import dynamic_prompt

@dynamic_prompt
def user_prompt(request):
    level = request.runtime.context.get("level", "normal")
    return f"当前用户等级：{level}，请根据等级调整解释深度。"
```


## 提示词与上下文工程

上下文工程页的核心不是“写更长提示词”，而是控制模型在每一步真正能看到什么。


**可控对象**

- system prompt
- messages
- tools
- model
- response format


## 瞬时上下文与持久上下文

| 类型 | 说明 |
| :-- | :-- |
| 瞬时上下文 | 当前轮次临时信息 |
| 持久上下文 | 会话历史、用户偏好、长期记忆 |


**理解**

- prompt 决定规则
- messages 决定当前对话依据
- memory / store 决定能否跨轮延续


# 使用建议

## 什么时候该改提示词

- 回答风格不稳定
- 工具调用时机不合理
- 输出格式不一致
- 角色边界不清晰


## 什么时候该改上下文

- 模型看不到关键历史
- 上下文过长导致跑偏
- 不同用户需要不同规则
- 工具需要读写运行时信息


**结论**

很多 Agent 失败，不一定是模型不行，更多时候是上下文给得不对。
