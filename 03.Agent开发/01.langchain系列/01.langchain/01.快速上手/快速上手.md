# 环境搭建

**Python 虚拟环境**

建议为 LangChain 项目单独创建虚拟环境，避免依赖冲突。



## python安装

**安装 LangChain**

安装 LangChain 核心包和常用社区包。



**使用**

```
pip install langchain python-dotenv langchain-deepseek langchain-openai
```

根据需要修改模型扩展包。



## Conda 安装-推荐

如果使用 Anaconda，也可以通过 Conda 管理 LangChain 包。



```
# 基本环境准备。网络问题，建议VPN切换到新加坡或者美国节点。
conda config --add channels conda-forge
conda config --set channel_priority strict

conda create -n langchain_dev python=3.12 -y
conda activate langchain_dev


# 优先用 conda 安装。如果conda找不到包，再使用pip安装。
conda install langchain python-dotenv langchain-deepseek langchain-openai -y
```



# API Key

推荐使用 `.env` 管理密钥，不要把密钥写死在代码中。

.env文件在项目根目录下。



**配置**

```
# model provider
MODEL_PROVIDER=deepseek

# DeepSeek API 配置
DEEPSEEK_API_KEY="sk-XXX"
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```



**读取**

```
from dotenv import load_dotenv

load_dotenv()
```



# 快速上手

**DeepSeek 集成**

LangChain 可以通过 `langchain-deepseek` 集成 DeepSeek 模型。



**使用**

```
import os
from dotenv import load_dotenv
from langchain.chat_models import init_chat_model

# 加载 .env
load_dotenv()

# 从环境变量获取配置
api_key = os.getenv("DEEPSEEK_API_KEY")
model_name = os.getenv("DEEPSEEK_MODEL", "deepseek-chat")  
base_url = os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com")  
model_provider = os.getenv("MODEL_PROVIDER")  

# 创建模型（使用 init_chat_model）
llm = init_chat_model(
    model=model_name,
    model_provider=model_provider,
    api_key=api_key,
    base_url=base_url,
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2
)

# 调用模型
response = llm.invoke("你好，请介绍下langgraph")

print(response.content)
```



本地测试用deepseek，具体使用哪个模型参考如下：

| 模型              | 用途                        | 特点                                |
| :---------------- | :-------------------------- | :---------------------------------- |
| deepseek-v4-flash | 通用聊天模型                | 支持 Tool Calling 与结构化输出      |
| deepseek-v4-pro   | 推理模型（deepseek-v4-pro） | 更强推理能力，但不支持 Tool Calling |

deepseek不支持图片，视频等多模态输入。
