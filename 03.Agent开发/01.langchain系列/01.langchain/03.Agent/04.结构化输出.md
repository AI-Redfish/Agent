# response_format

把 Pydantic 模型传给 `create_agent()` 的 `response_format` 参数即可。

```python
from dotenv import load_dotenv
load_dotenv()

from pydantic import BaseModel, Field
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage


class CourseInfo(BaseModel):
    """课程提取结果"""
    course_name: str = Field(description="课程名称")
    difficulty: str = Field(description="难度：入门/进阶/高级")
    estimated_hours: int = Field(description="预计学习时长（小时）")
    is_free: bool = Field(description="是否免费")


model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)

agent = create_agent(
    model=model,
    response_format=CourseInfo,
    system_prompt="你是课程助手，从用户描述中提取课程信息。",
)

result = agent.invoke({
    "messages": [HumanMessage(
        content="我最近在学习 Python3 基础教程，是入门级别的，大概要学 20 个小时，而且是完全免费的"
    )]
})

course = result["structured_response"]
print(course.course_name)
print(course.difficulty)
print(course.estimated_hours)
print(course.is_free)
```



## 返回结果位置

结构化输出结果通常从：

```python
result["structured_response"]
```

中获取。



## 返回的不是普通字典

返回结果通常是 Pydantic 模型实例，而不是普通 `dict`。



**特点**

- 可以用 `course.course_name` 这种属性方式访问
- IDE 补全更友好
- 字段类型更明确



# 与工具一起使用

`response_format` 和 `tools` 可以同时使用。

也就是说：

- Agent 先调用工具获取信息
- 最后再按指定结构输出结果



```python
from pydantic import BaseModel, Field
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage
from langchain.tools import tool


@tool
def search_course(keyword: str) -> str:
    """搜索课程信息"""
    courses = {
        "python": "Python3 基础教程 | 入门 | 免费 | 30章 | 约20小时",
        "java": "Java 基础教程 | 入门 | 免费 | 35章 | 约25小时",
    }
    return courses.get(keyword.lower(), "未找到相关课程")


class CourseRecommendation(BaseModel):
    course_name: str = Field(description="推荐课程名称")
    reason: str = Field(description="推荐理由")
    difficulty: str = Field(description="难度")


model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)

agent = create_agent(
    model=model,
    tools=[search_course],
    response_format=CourseRecommendation,
    system_prompt="你是课程顾问。先查询课程再给出推荐。",
)

result = agent.invoke({
    "messages": [HumanMessage(content="我想学 Python，有什么推荐？")]
})

rec = result["structured_response"]
print(rec.course_name)
print(rec.reason)
print(rec.difficulty)
```



## 适合场景

- 先查数据库/知识库，再输出固定格式结果
- 先调用工具，再生成推荐对象
- 多步处理后返回标准业务对象



# 复杂嵌套结构

Pydantic 不只是支持简单字段，也支持：

- 嵌套对象
- 列表
- 枚举 / Literal



```python
from pydantic import BaseModel, Field
from typing import Literal


class Topic(BaseModel):
    name: str = Field(description="知识点名称")
    order: int = Field(description="学习顺序")
    minutes: int = Field(description="建议学习分钟数")


class LearningPlan(BaseModel):
    goal: str = Field(description="学习目标概述")
    level: Literal["入门", "进阶", "高级"] = Field(description="难度级别")
    total_hours: float = Field(description="总时长（小时）")
    topics: list[Topic] = Field(description="知识点列表")
```



## 适合场景

- 学习计划
- 订单对象
- 用户画像
- 报表结构
- 多层级业务对象



# 不使用 Agent 的写法

如果只是做信息提取，不需要工具调用，也不需要完整 Agent 流程，可以直接在 Model 上使用：

```python
with_structured_output()
```



```python
from pydantic import BaseModel, Field
from langchain.chat_models import init_chat_model


class SentimentResult(BaseModel):
    sentiment: str = Field(description="积极/消极/中性")
    score: float = Field(description="情感强度 0~1")
    keywords: list[str] = Field(description="关键情感词")


model = init_chat_model("deepseek:deepseek-v4-flash", temperature=0)
structured_model = model.with_structured_output(SentimentResult)

result = structured_model.invoke("这个教程真的很好，强烈推荐")
print(result.sentiment)
print(result.score)
print(result.keywords)
```



## 什么时候直接用 Model

适合：

- 文本信息抽取
- 分类
- 情感分析
- 简单结构化整理



不太适合：

- 需要工具调用
- 需要多步骤推理
- 需要完整 Agent 状态管理



**理解**

如果你的需求只是“把文本转成结构化对象”，`with_structured_output()` 通常比 `create_agent()` 更轻。



# 字段设计建议

## Field(description=...)

示例里多次使用了：

```python
Field(description="字段说明")
```

这个描述不仅是给人看的，也是在告诉模型这个字段应该放什么内容。



**建议**

- 字段名清晰
- description 写明确
- 枚举值尽量收敛
- 类型尽量具体



## 示例

不推荐：

```python
value: str
```

推荐：

```python
difficulty: str = Field(description="难度：入门/进阶/高级")
```



# 使用建议

## 适合结构化输出的场景

- 从文本里抽取固定字段
- 生成业务对象
- 输出固定格式响应
- 结果要直接给后端程序消费



## 不适合只用自由文本的场景

- 后续代码要依赖字段名取值
- 输出格式必须稳定
- 需要减少正则解析



## 实战建议

- 先定义好 Pydantic 模型
- 字段描述尽量写清楚
- 抽取类任务优先低 `temperature`
- 简单提取优先 `with_structured_output()`
- 需要工具和工作流时再用 `create_agent(..., response_format=...)`
