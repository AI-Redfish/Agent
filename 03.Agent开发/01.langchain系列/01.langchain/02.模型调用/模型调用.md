# 模型初始化

## init_chat_model()

`init_chat_model()` 是 LangChain 推荐的统一模型入口。



**使用**

```
from langchain.chat_models import init_chat_model

model = init_chat_model(
    model='deepseek-chat',
    model_provider='deepseek'
)
```



**参数说明**

| 参数 | 说明 |
| :-- | :-- |
| `model` | 模型名称，如 `deepseek-chat` |
| `model_provider` | 模型供应商，如 `deepseek`、`openai` |
| `temperature` | 控制输出随机性 |
| `max_tokens` | 控制最大输出长度 |
| `timeout` | 请求超时时间 |
| `max_retries` | 失败重试次数 |
| `base_url` | 自定义兼容接口地址 |



## 常用配置

模型调用建议显式配置随机性、输出长度、超时和重试。



**使用**

```
model = init_chat_model(
    'deepseek-chat',
    model_provider='deepseek',
    temperature=0,
    max_tokens=512,
    timeout=30,
    max_retries=2,
)
```



**temperature 建议**

| 场景 | 推荐值 |
| :-- | :-- |
| 代码生成、事实问答、分类 | `0` 到 `0.3` |
| 普通问答、总结 | `0.3` 到 `0.7` |
| 文案、创意、头脑风暴 | `0.7` 到 `1.0` |



# 调用方式

## invoke()

同步调用模型，等待完整结果返回。



**使用**

```
response = model.invoke('请解释 LangChain 的作用')
print(response.content)
```



**使用场景**

- 普通问答
- 脚本调用
- 后端接口中等待完整结果



## stream()

流式调用模型，适合聊天界面逐步展示内容。



**使用**

```
for chunk in model.stream('写一段 LangChain 简介'):
    print(chunk.content, end='')
```



**使用场景**

- Web 聊天界面
- 命令行实时输出
- 长文本生成



# 高级能力

## bind_tools()

`bind_tools()` 用来把工具 schema 绑定到模型，让模型知道可用工具。



**使用**

```
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索指定关键词。"""
    return '搜索结果'

model_with_tools = model.bind_tools([search])
response = model_with_tools.invoke('搜索 LangChain Agent')
```



**说明**

- `bind_tools()` 只是让模型知道工具。
- 是否真正执行工具，通常交给 Agent 工作流处理。



## 结构化输出

结构化输出适合信息抽取、分类、表单生成等场景。



**使用**

```
from pydantic import BaseModel, Field

class Contact(BaseModel):
    name: str = Field(description='姓名')
    phone: str = Field(description='手机号')

structured_model = model.with_structured_output(Contact)
result = structured_model.invoke('张三，电话 13800000000')
```



**输出策略**

| 策略 | 说明 | 适合场景 |
| :-- | :-- | :-- |
| `ToolStrategy` | 通过工具调用模拟结构化输出 | 兼容性更强 |
| `ProviderStrategy` | 使用模型供应商原生结构化能力 | 模型支持原生 schema 时更稳 |
| 自动策略 | LangChain 根据模型能力选择 | 默认推荐 |



**建议**

- 普通文本问答使用 `invoke()`。
- 聊天界面使用 `stream()`。
- 信息抽取优先使用 `with_structured_output()`。
- 生产环境建议固定 `timeout` 和 `max_retries`。
