# 工具定义

## @tool

`@tool` 用来把普通 Python 函数注册成 LangChain 工具。


**使用**

```python
from langchain_core.tools import tool

@tool
def add(a: int, b: int) -> int:
    """计算两个整数之和。"""
    return a + b
```


## 工具编写规范

| 项目 | 建议 |
| :-- | :-- |
| 函数名 | 使用清晰动词 |
| 参数类型 | 明确声明 |
| docstring | 写清用途和返回值 |
| 返回值 | 尽量稳定、可读 |
| 异常 | 转成可理解错误 |


## 自定义工具属性

工具页专门强调可以自定义名字、描述、参数 schema，这些内容都会进入模型可见上下文。

工具写得越清楚，模型越不容易乱传参数。


# 工具注册与调用

## 注册工具

工具需要注册到 Agent，模型才知道可以调用它。


**使用**

```python
agent = create_agent(
    model=model,
    tools=[add],
    system_prompt="你可以根据需要调用工具。"
)
```


## 工具返回值

工具返回值应尽量短、稳、可解析。

不建议：

- 返回过长噪声文本
- 返回格式不稳定的自由文本
- 把系统异常直接抛给模型


## 错误处理

工具页和运行时页都强调外部调用要包好异常、超时和权限。


**使用**

```python
from langchain_core.tools import ToolException

raise ToolException("没有找到订单")
```


# 工具高级能力

## 访问上下文

工具不仅能收显式参数，也能读取运行时注入内容。


## 状态注入

**使用**

```python
from typing import Annotated
from langgraph.prebuilt import InjectedState

@tool
def read_context(state: Annotated[dict, InjectedState]) -> str:
    """读取当前 Agent 状态。"""
    return str(state.get("messages", [])[-1])
```


## 存储注入

**使用**

```python
from typing import Annotated
from langgraph.store.base import BaseStore
from langgraph.prebuilt import InjectedStore

@tool
def get_preference(store: Annotated[BaseStore, InjectedStore], key: str) -> str:
    """读取用户偏好。"""
    item = store.get(("preferences",), key)
    return item.value if item else "未设置"
```


## 其他可注入信息

工具页与运行时页提到，工具里还可以访问：

- runtime context
- execution info
- server info
- writer / 流写入器


# 运行时

## Runtime

运行时页的重点是：工具和中间件并不只拿到入参，还能拿到执行环境信息。


**作用**

- 读取权限
- 读取上下文
- 获取执行信息
- 获取服务器信息


## 权限控制

运行时页明确把权限列为重点，说明查询类和执行类工具应区别对待。


**建议**

- 查询类工具可直接执行
- 修改、删除、发送、支付类工具要做确认
- 高风险工具最好结合人工干预或 guardrails


# MCP

## MCP 是什么

MCP 是 Model Context Protocol，用统一协议把工具、资源、提示暴露给模型。


**核心能力**

- tools
- resources
- prompts


## 传输方式

官方页重点提到两类传输：

- `stdio`
- `HTTP`


## 适合场景

- 让 Agent 接统一外部工具系统
- 接入现成 MCP Server
- 把内部能力标准化暴露给模型


## 高级特性

MCP 页还提到：

- 工具拦截器
- 进度通知
- 日志记录
- 请求用户输入


**结论**

LangChain 的工具系统不只是函数调用，还包括状态、存储、权限、运行时和协议层整合。
