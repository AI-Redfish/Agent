# 工具定义

## @tool

`@tool` 可以把普通 Python 函数转换为 LangChain 工具。



**使用**

```
from langchain_core.tools import tool

@tool
def add(a: int, b: int) -> int:
    """计算两个整数之和。"""
    return a + b
```



**编写规范**

| 项目 | 建议 |
| :-- | :-- |
| 函数名 | 使用动词短语，如 `query_order` |
| 参数类型 | 明确标注类型 |
| docstring | 写清楚工具用途和返回值 |
| 返回值 | 尽量返回简洁、可读、结构稳定的内容 |
| 异常 | 捕获业务异常，转换为可理解信息 |



## 注册工具

工具需要注册到 Agent 后，模型才能在 Agent 流程中调用它。



**使用**

```
from langchain.agents import create_agent

agent = create_agent(
    model=model,
    tools=[add],
    system_prompt='你可以根据需要调用工具。'
)
```



# 工具高级特性

## return_direct

`return_direct=True` 表示工具结果直接作为最终结果返回，不再交给模型二次总结。



**使用**

```
@tool(return_direct=True)
def get_policy(name: str) -> str:
    """查询政策原文。"""
    return '政策原文内容'
```



**使用场景**

- 订单状态
- 下载链接
- 固定查询结果
- 不需要模型二次润色的确定性内容



## ToolException

`ToolException` 用于表示工具内部的可预期业务错误。



**使用**

```
from langchain_core.tools import ToolException

raise ToolException('没有找到订单')
```



**建议**

- 业务错误返回用户可理解的信息。
- 系统错误记录日志后再包装。
- 外部接口调用要加超时和重试。



# 状态与存储注入

## InjectedState

`InjectedState` 允许工具读取当前 Agent 状态。



**使用**

```
from typing import Annotated
from langgraph.prebuilt import InjectedState

@tool
def read_context(state: Annotated[dict, InjectedState]) -> str:
    """读取当前 Agent 状态。"""
    return str(state.get('messages', [])[-1])
```



## InjectedStore

`InjectedStore` 允许工具读取跨会话持久化数据。



**使用**

```
from typing import Annotated
from langgraph.store.base import BaseStore
from langgraph.prebuilt import InjectedStore

@tool
def get_preference(store: Annotated[BaseStore, InjectedStore], key: str) -> str:
    """读取用户偏好。"""
    item = store.get(('preferences',), key)
    return item.value if item else '未设置'
```



**对比**

| 能力 | 作用 | 生命周期 |
| :-- | :-- | :-- |
| `InjectedState` | 读取当前 Agent 运行状态 | 单次会话或线程 |
| `InjectedStore` | 读取持久化数据 | 跨会话保存 |



**建议**

- 查询类工具可以直接执行。
- 修改、删除、发送、支付类工具要加权限和确认。
- 工具说明越清晰，模型越不容易乱传参数。
